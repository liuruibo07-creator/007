## 一、Git 概述

Git 是一款**版本控制工具**，用于管理代码的历史版本、多人协作开发。

---

## 二、Git 下载安装配置

| 步骤 | 说明 |
|---|---|
| **下载** | 官网下载对应操作系统的安装包 |
| **安装** | ⚠️ 安装路径**不要有中文**，避免后续使用出现编码/路径问题 |
| **配置** | 安装完成后需要配置用户名和邮箱 |

**配置用户名和邮箱：**

```bash
git config --global user.name  用户名
git config --global user.email  邮箱
```

## 三、Git 相关概念

### 3.1 仓库相关

| 概念 | 说明 |
|---|---|
| **本地仓库** | = 版本库 + 工作区 |
| **远程仓库** | 托管在服务器上的仓库，常见平台见下表 |
| **版本库** | 即 `.git` 目录，保存所有版本历史 |
| **工作区** | 除 `.git` 目录之外的部分，即实际编辑的文件区域 |
| **暂存区** | `.git` 目录下的 `index` 文件，**首次执行 `git add` 命令时才会产生** |

### 3.2 常见远程仓库平台

| 平台 | 说明 |
|---|---|
| **GitHub** | 国外平台，全球最大的代码托管平台 |
| **Gitee（码云）** | 国内平台 |
| **GitLab** | 常用于企业内部私有化搭建 |

### 3.3 本地仓库与远程仓库的关系图

```
本地仓库 = 版本库(.git) + 工作区
                │
              git add
                ↓
             暂存区(index)
                │
             git commit
                ↓
              版本库
                │
        git push / git pull
                ↓
             远程仓库
```

## 四、Git 常用命令

### 4.1 仓库初始化 / 克隆

| 命令 | 作用 | 适用场景 |
|---|---|---|
| `git init` | 创建本地仓库 | 通常由**项目组长**对初始项目文件夹执行，将其变成本地仓库 |
| `git clone 远程仓库地址` | 克隆远程仓库到本地 | 通常由**项目组员**拉取组长分享的初始项目 |

### 4.2 工作区 / 暂存区 / 版本库 操作

| 命令 | 作用 |
|---|---|
| `git add 文件列表` 或 `git add .` | 将工作区文件添加到暂存区 |
| `git status` | 查看文件状态（见下） |
| `git reset` | 将暂存区文件回退到工作区 |
| `git commit 文件1 文件2 ... -m "提交消息"` | 将暂存区文件提交到版本库；不跟文件列表则提交暂存区全部内容；**提交消息必须书写** |

**`git status` 文件状态：**

| 状态 | 说明 |
|---|---|
| **未跟踪（Untracked）** | 新建文件的初始状态 |
| **已跟踪（Tracked）** | 一旦通过命令对文件进行过操作（如 `git add`）后即为此状态 |

### 4.3 远程仓库操作

| 命令 | 作用 |
|---|---|
| `git remote` | 查看远程仓库。若本地仓库由 `git init` 创建，默认查不到远程仓库；若由 `git clone` 创建，默认能查到远程仓库 `origin` |
| `git remote add 远程仓库别名 远程仓库URL` | 添加远程仓库（可添加多个） |
| `git remote remove 远程仓库别名` | 删除指定别名的远程仓库 |
| `git push 远程仓库别名 本地分支名称` | 将本地分支推送到远程仓库（默认主分支为 `master`） |
| `git pull 远程仓库别名 远程仓库分支名称` | 从指定远程仓库拉取指定分支 |

### 4.4 分支操作

| 命令 | 作用 |
|---|---|
| `git branch` | 查询本地仓库分支 |
| `git branch -r` | 查询远程仓库分支 |
| `git branch -a` | 查询所有（本地+远程）分支 |
| `git branch 分支名称` | 创建分支 |
| `git checkout 分支名称` | 切换分支 |
| `git branch -d 分支名称` | 删除分支 |
| `git merge 分支名称` | 将指定分支合并到当前分支 |

### 4.5 标签（Tag）操作

| 命令 | 作用 |
|---|---|
| `git tag` | 查看标签 |
| `git tag 标签名` | 创建标签 |
| `git tag -d 标签名` | 删除本地标签 |
| `git push 远程仓库别名 标签名` | 推送指定标签到远程仓库 |
| `git push 远程仓库别名 :标签名` | 删除远程仓库上的指定标签 |
| `git checkout -b 分支名 本地tag名` | 基于指定标签创建新分支并切换过去 |

## 📌 本日重点回顾

1. **本地仓库 = 版本库（`.git`） + 工作区**；暂存区（`index` 文件）在**第一次** `git add` 时才产生
2. `git init`（组长初始化）与 `git clone`（组员拉取）适用场景不同，二者创建的仓库对 `git remote` 的查询结果也不同
3. 文件状态流转：工作区（未跟踪/已跟踪）→（`git add`）暂存区 →（`git commit`）版本库 →（`git push`/`git pull`）远程仓库
4. 分支相关命令（`branch`/`checkout`/`merge`）与标签相关命令（`tag`/`checkout -b`）结构非常对称，注意区分二者的应用场景
