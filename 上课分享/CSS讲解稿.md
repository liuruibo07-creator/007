# CSS 课堂讲解稿（约10分钟）

---

## 【开场 · 约30秒】

好，同学们注意一下，接下来我用10分钟给大家分享一下 CSS 的核心知识点。

我们学 HTML 是搭结构，学 CSS 就是给这个结构"化妆"——控制颜色、大小、布局。一句话概括：**CSS 就是层叠样式表，专门管 HTML 长什么样。**

---

## 【一、引入方式 · 约1分钟】

首先说 CSS 怎么引入到页面里，有三种方式。

第一种，**内部样式**，就是在 HTML 的 `<head>` 里写一个 `<style>` 标签，把 CSS 写在里面，适合我们平时练习用。

第二种，**外部样式**，单独建一个 `.css` 文件，然后用 `<link>` 标签引入进来。这是实际工作中最推荐的方式，结构和样式分离，维护起来方便。

第三种，**行内样式**，直接在标签上写 `style` 属性。这个一般不单独用，主要是配合 JavaScript 动态改样式的时候才用。

> **记住：工作里用外部样式，学习阶段用内部样式就行。**

---

## 【二、选择器 · 约4分钟】

接下来是重点——**选择器**，就是"你想给哪个元素加样式"。我把它分成几类来讲。

### 基础选择器

最基本的四个：
- **通配符 `*`**：选中页面所有元素，常用来清除默认的边距。
- **标签选择器 `div`**：选中所有这个标签。
- **类选择器 `.box`**：选中所有 class 等于 box 的元素，用得最多。
- **ID 选择器 `#header`**：选中那个唯一的 id，页面里只能有一个。

### 层次选择器

这四个描述的是元素之间的关系：
- `A B`（空格）—— **后代选择器**，A 里面所有的 B，不管嵌套多深。
- `A > B` —— **子代选择器**，只找 A 的直接子元素 B。
- `A + B` —— **相邻兄弟**，紧跟在 A 后面的那一个 B。
- `A ~ B` —— **通用兄弟**，A 后面所有的 B。

> 最常用的是前两个，空格和大于号，一定要区分清楚。

### 伪类选择器

伪类是选中元素的某种"状态"或"位置"，最常用的是：
- `:hover` —— 鼠标悬停上去的状态，做导航高亮必用。
- `:nth-child(N)` —— 第几个子元素。

这里有个容易混的点：`:nth-child` 和 `:nth-of-type` 的区别。

举个例子：父元素里有一个 `<h2>` 和三个 `<p>`，如果用 `p:nth-child(1)`，它找的是"第1个子元素，并且是p"，但第1个子元素是 h2，所以什么都选不中。而 `p:nth-of-type(1)` 找的是"第1个p类型的元素"，就能正确选中第一个p。

**`:nth-child` 看位置，`:nth-of-type` 看类型。**

`nth-child` 还有一些公式写法：`2n` 选偶数行，`2n+1` 选奇数行，`-n+3` 选前三项，做表格隔行变色就靠这个。

### 属性、伪元素、并集交集

快速过一下：

**属性选择器**——根据标签的属性来选，比如 `input[type="text"]` 只选文本输入框，`a[href^="https"]` 选所有 https 开头的链接。

**伪元素选择器** `::before` / `::after`——在元素内容前后插入虚拟内容，不需要改 HTML 结构。有一点必须记住：**`content` 属性一定要写**，哪怕写空字符串，否则伪元素不生效。

**并集和交集**：`h1, h2, h3` 用逗号，是并集，共用同一套样式；`div.box` 不加空格紧挨着写，是交集，同时满足两个条件才选中。

## 【三、常见样式属性 · 约3.5分钟】

选择器解决了"选谁"，属性解决"改什么"。

### 字体 font

五个核心属性：
- `font-size`：字号，常用 `16px`。
- `font-weight`：粗细，`700` 或 `bold` 是加粗，`400` 或 `normal` 是正常。
- `font-style`：斜体用 `italic`，正常用 `normal`。
- `font-family`：字体，一般写 `"Microsoft YaHei"` 微软雅黑，后面跟备用字体。
- `line-height`：行高，推荐用 `1.5` 这种倍数写法，更灵活。

这五个可以用 **font 复合属性**合并成一行：`font: italic bold 16px/1.5 "Microsoft YaHei"`，顺序是：斜体 加粗 字号/行高 字体。注意 `font-size` 和 `font-family` 这两个是必须写的。

### 文本 text

- `color`：颜色，支持英文单词、十六进制 `#333`、`rgb()`、`rgba()`，`rgba` 第四个参数是透明度。
- `text-align`：水平对齐，`center` 居中常用。
- `text-indent: 2em`：首行缩进，`1em` 等于一个字符宽度，所以 `2em` 就是缩进两个字。
- `text-decoration`：`none` 去掉下划线（链接默认有下划线，一般都要去掉）、`underline` 加下划线、`line-through` 删除线。

### 背景 background

- `background-color`：背景色。
- `background-image: url(路径)`：背景图片。
- `background-repeat`：是否平铺，一般设 `no-repeat`。
- `background-position`：位置，`center center` 就是居中。
- `background-size`：`cover` 等比例铺满整个区域，最常用；`contain` 是等比例完整显示。

同样有复合写法：`background: #fff url(bg.png) no-repeat center/cover`，一行搞定。

### 其他两个常用的

**`box-shadow` 盒子阴影**：格式是"水平偏移 垂直偏移 模糊半径 扩散半径 颜色"，做卡片效果经常用 `0 4px 16px rgba(0,0,0,0.15)` 这个写法。加 `inset` 变成内阴影。

**`opacity` 透明度**：0 是完全透明，1 是完全不透明，但它会连子元素一起变透明。如果只想让背景色透明，用 `rgba()` 来写颜色值，这样子元素不受影响。
