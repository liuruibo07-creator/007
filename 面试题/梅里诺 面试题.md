### java反射机制 、应用反射
![](assets/梅里诺%20面试题/file-20260831102126492.png)
```java
//方式一 类名.class属性  
Class<Cat> c1 = Cat.class;  
//方式二 Class.forName(全类名)  
Class<?> c2 = Class.forName("com.scedu.code.d1_reflect.Cat");  
//方式三 对象名.getClass()  
Cat cat = new Cat();  
Class<? extends Cat> c3 = cat.getClass();

System.out.println(c1==c2);  
System.out.println(c1==c3);

// 创建实例，newInstance() 在 JDK9 已标记过时
Constructor<?> constructor = clazz.getConstructor();
Object obj = constructor.newInstance();

// 访问私有字段
Field field = clazz.getDeclaredField("secretField");
field.setAccessible(true);  // 暴力破解访问权限
Object value = field.get(obj);

// 调用方法
Method method = clazz.getMethod("doSomething", String.class);
Object result = method.invoke(obj, "参数");

```

# 第五天
### java中泛型的作用
把类型检查从运行时提前到编译时（类型安全，消除强转，代码复用）
### 泛型擦除
java编译器在编译阶段把所有泛型都抹去的过程

### java的spi机制是什么

jdk内置的一套服务发现机制，核心思想是接口定义在调用方，实现类放在服务提供方，运行时通过配置文件动态加载。
工作流程
1.调用方定义服务接口
2.服务方提供实现接口
3.服务提供方在jar包的META-INFX下创建以接口全限定名命名的文件

### java泛型的上下界定符

限制泛型参数的类型范围
```java
<? extenda T>  上界限定符，必须是T或者T的子类
<? super T>下界限定符 必须是T的父类或者T
```

### java的Inteager缓存池

jvm为了减少小整数对象的重复创建的一种优化机制
-128-127范围内的Inteager对象会被先缓存起来，自动装箱时直接返回缓存对象，不用每次new一个新的对象

### 什么叫深拷贝和浅拷贝

浅拷贝是复制对象本身，但引用类型的字段还是指向原来的内存地址，共享引用对象，一个变另一个也跟着变
深拷贝是把对象和它内部所有引用的对象都递归赋值一遍，新旧对象互相独立，互不影响。

### java的类加载过程
类加载就是把.class文件的二进制数据读进内存，经过校验和转换最终变成jvm能用的class对象
总体上来说分为：加载、验证、准备、解析、初始化 五阶段

### Bigdemical

java提供的高精度数值计算类，专门解决float和double的精度丢失问题。涉及到钱的计算必须用BigDemical
BigDemical能保证精度不丢失，核心在于它压根不用浮点数那套二进制表示法，而是用整数加小数点位置存储数据

### final
final是个修饰符，用来锁死类和方法、变量
finally是异常处理的一部分，配合try-catch使用，无论try是否抛出异常，它都执行，通常用来释放资源
finalize()是object类的一个方法jvm在回收对象时会调用它，让对象做最后的清理

### new String ('ggg')在java中创建几个对象

如果字符串常量池没有，现在堆上创建一个放常量池里，然后new String（）在堆上创建一个
如果常量池已经有了，就只在对上创建一个，字符串常量池直接复用。

### 静态方法和实例方法的区别

静态方法属于类，不需要对象就能调用，实例方法属于对象必须new出来才能用
静态方法里不能用this,也不能直接访问实例变量和方法
实例方法能调用静态方法和静态变量

### DTO 、VO 、PO、BO、DAO、POJO
PO 存数据库的，持久化对象
DTO  数据传输对象，用于跨层跨业务传递数据
VO 视图对象，给前端页面的数据包装
DAO 数据访问对象  是接口或类，负责与数据库打交道实行增删改查
POJO
BO 业务对象 封装业务逻辑，包含多个PO（业务层专用）
