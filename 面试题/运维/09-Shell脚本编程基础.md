## 一、Shell 与脚本

Shell 是命令解释器，负责解析命令并调用程序或执行内建操作。Shell 脚本将一组命令写入文件进行批量执行，常以 `.sh` 结尾，但扩展名不是执行的必要条件。

```bash
#!/bin/bash
echo 'Hello, Linux'
```

首行 `#!` 指定直接执行脚本时使用的解释器。

| 执行方式 | 特点 |
| --- | --- |
| `bash script.sh` | 明确使用 Bash，通常要求脚本可读，不要求脚本执行位 |
| `chmod u+x script.sh` 后 `./script.sh` | 直接执行，需要执行权限，解释器通常由 shebang 指定 |

## 二、入门案例：覆盖重定向

原图用清空系统日志讲解重定向。这里将可运行示例改为独立演示文件，保留知识点；实际系统日志通常使用 `/var/log/messages` 等路径，也可能由 journal 管理。

```bash
#!/bin/bash
demo_log="${TMPDIR:-/tmp}/shell-note-demo-$$.log"
printf 'example log\n' > "$demo_log"
cat /dev/null > "$demo_log"
echo "演示日志已清空：$demo_log"
```

`>` 覆盖重定向，文件已存在时会截断；`>>` 追加到文件末尾。业务日志应结合留存要求和日志轮转机制管理。

## 三、变量定义与命名

```bash
app_name='webapp'                       # 等号两侧不能有空格
echo "$app_name"
echo "${app_name}_backup"               # 花括号明确变量名边界
unset app_name                         # 删除变量时不加 $
```

变量名由字母、数字、下划线组成，不能以数字开头，区分大小写。命名应清晰，避免覆盖 `PATH`、`HOME` 等系统变量；课程要求避免关键字，可作为命名规范遵循。

## 四、普通变量、局部变量与环境变量

| 类型 | 定义方式 | 有效范围 |
| --- | --- | --- |
| 普通 Shell 变量 | `name=value` | 当前 Shell；不会自动导出给子进程 |
| 函数局部变量 | 函数中 `local name=value` | 当前函数调用及其动态作用域 |
| 环境变量 | `export APP_ENV=dev` | 当前 Shell 及其启动的子进程 |

> **概念校正：**普通的 `name=value` 不会自动成为“函数局部变量”；在 Bash 函数中需使用 `local`。导出的变量由子进程继承，子进程修改不会反向修改父 Shell。

常见环境变量包括 `$HOME`、`$PWD`、`$USER`、`$SHELL`。其中 `$SHELL` 通常表示用户配置的登录 Shell，未必就是当前正在执行脚本的解释器。

### 临时与持久配置

- 会话中执行 `export`：仅在当前会话及其后续子进程中生效。
- `~/.bash_profile`：用户级登录 Bash 配置。
- `/etc/profile`：系统级登录 Shell 配置，具体行为依 Shell 而异。
- 非登录交互 Bash 通常读取 `~/.bashrc`，不要认为任意脚本都会自动读取 profile。

原图以 JDK 8 为环境变量案例，可按实际安装路径配置：

```bash
export JAVA_HOME=/opt/jdk8
export PATH="$JAVA_HOME/bin:$PATH"
echo "$JAVA_HOME"
```

这是环境变量示例，实际 JDK 目录需与安装结果一致。

## 五、位置参数与状态变量

| 变量 | 含义 |
| --- | --- |
| `$0` | 脚本调用名；具体形式取决于调用方式 |
| `$1`、`$2` | 第一、第二个参数 |
| `${10}` | 第十个参数，需使用花括号 |
| `$#` | 参数个数 |
| `"$*"` | 将所有位置参数合为一个词，以 IFS 首字符连接 |
| `"$@"` | 每个位置参数仍是独立的词，适合原样转交 |
| `$?` | 上一条命令的退出状态，通常 0 成功，非 0 表示失败或其他状态 |

`$*` 与 `$@` 的差别应结合双引号讨论；未加引号时还会发生分词和文件名展开。

```bash
#!/bin/bash
printf '脚本：%s，参数数：%s\n' "$0" "$#"
printf '参数：<%s>\n' "$@"
```

`$?` 会被下一条命令覆盖，需要时立即保存：

```bash
cp source.txt target.txt
copy_status=$?
echo "复制退出状态：$copy_status"
```

## 六、引号与命令替换

| 写法 | 行为 |
| --- | --- |
| `'纯文本 $name'` | 原样输出，不展开变量 |
| `"内容 $name"` | 展开变量，并保护展开结果不被分词和通配符展开 |
| `result=$(command)` | 将命令标准输出赋给变量，移除末尾换行 |
| 反引号命令替换 | 也支持，通常优先使用更易阅读和嵌套的 `$()` |

```bash
name='Linux'
echo '$name'                            # 输出 $name
echo "$name"                            # 输出 Linux
today=$(date +%F)
echo "日期：$today"
```

变量用于文件路径或参数时，通常写作 `"$var"`，避免空格拆分和通配符展开。

## 七、算术运算

原图列出 `+ - * / %` 以及 `++`、`--`。Bash 常用算术展开 `$((表达式))` 和算术命令 `((表达式))`：

```bash
a=10
b=3
echo "$((a + b))"                       # 13
echo "$((a / b))"                       # 3，整数除法
echo "$((a % b))"                       # 1，取余
((a++))
((b--))
```

Bash 内置算术通常是整数运算，变量赋值 `a=1+2` 不会自动得到数值 3；应使用 `a=$((1 + 2))`。

## 八、面试速记

- **变量赋值有什么格式要求？**等号两侧不加空格，取值时用 `$name` 或 `${name}`。
- **单引号与双引号区别？**单引号保留字面内容，双引号允许变量等展开并保护结果。
- **脚本转交参数用什么？**通常使用 `"$@"`，保持原始参数边界。
- **如何取得命令结果和执行状态？**`$(命令)` 获取标准输出，`$?` 获取退出状态。
- **环境变量与局部变量区别？**`export` 控制子进程继承；`local` 控制函数内的变量作用域。
