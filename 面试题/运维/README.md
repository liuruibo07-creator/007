1. **建立基础：**运维职责、Linux 目录和网络通信概念。
2. **掌握操作：**文件、用户权限、服务、进程和网络命令。

5. **串联自动化：**Shell 变量、参数、状态码与 crontab。

## 三、重点辨析

| 容易混淆的点 | 应掌握的结论 |
| --- | --- |
| SSH 公钥认证 | 私钥签名、公钥验签，用户认证与主机身份验证需区分 |
| tar 打包和压缩 | `-c` 创建归档，gzip 压缩需 `-z` |
| 启动与开机自启 | `start` 与 `enable` 控制不同状态 |
| 文件与目录的 x 权限 | 文件执行、目录遍历；`bash file.sh` 与 `./file.sh` 要求不同 |
| LV 与文件系统扩容 | 扩大 LV 后还需扩展文件系统 |
| RAID 与备份 | RAID 冗余不能替代独立备份 |
| rsync 归档模式 | `-a` 不包含所有元数据；目录末尾斜杠影响目标层级 |
| DNS 根服务器数量 | 13 个命名标识对应多个实际服务实例 |
| Shell 参数转交 | 通常使用 `"$@"` 保持参数边界 |
