## 一、JS 概述与基础

> **Day 04** · JS 入门

### 1.1 什么是 JavaScript

JavaScript 是**运行在浏览器中的脚本语言**，用来实现网页的动态交互效果。

### 1.2 JS 书写位置

| 类型 | 位置 | 说明 |
|------|------|------|
| **内部 JS** | `</body>` 标签上方，写在 `<script>` 标签中 | 最常用 |
| **外部 JS** | 写在 `.js` 文件中，通过 `<script src="">` 引入 | 推荐用于大型项目 |
| **行内 JS** | 直接写在 HTML 标签属性中 | 了解即可 |

> ⚠️ **注意事项**
> - 外部 JS 文件中直接写代码，**不要加 `<script>` 标签**
> - `<script src="">` 引入外部文件时，其标签内部写的代码**无效**

### 1.3 JS 注释

```js
// 单行注释（快捷键：Ctrl + /）

/* 多行注释
   （快捷键：Ctrl + Shift + /）*/
```

### 1.4 结束符号

- 语法上可写可不写分号 `;`
- **统一约定：不写分号**（以公司开发手册为准）

### 1.5 输入 / 输出语句

| 方法 | 类型 | 说明 |
|------|------|------|
| `alert()` | 输出 | 弹出警告框 |
| `document.write()` | 输出 | 输出到 body 中，支持写标签 |
| `console.log()` | 输出 | 输出到控制台，调试用 |
| `prompt()` | 输入 | 弹出输入提示框 |

## 二、变量、常量与数据类型

> **Day 04 & 05**

### 2.1 变量

**变量**是存储数据的容器，可理解为一个"盒子"。

```js
// 声明变量（推荐 let，不推荐旧版 var）
let name = 'Tom'

// 修改变量
name = 'Jerry'

// 一行定义多个
let a = 10, b = 20
```

#### 变量命名规则（必须遵守）

- 由字母、数字、下划线 `_`、`$` 组成
- **不能以数字开头**
- **区分大小写**
- **不能与关键字同名**

#### 变量命名规范（建议遵守）

- **见名知意**
- 使用**小驼峰命名法**：第一个单词首字母小写，后续每个单词首字母大写（如 `myName`）

#### 变量交换数据

```js
// 使用第三方临时变量（temp 打头）
let temp = a
a = b
b = temp
```

### 2.2 常量

**常量**是存储数据的容器，其中的数据**不能被修改**。

```js
const PI = 3.14  // 定义时必须赋值，之后不可修改
```

> 💡 当数据是**不可变的量**时，用 `const` 可以防止被误修改。

### 2.3 数据类型

#### 基本数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `number` | 整数和小数 | `10`、`3.14` |
| `string` | 字符串（推荐单引号） | `'hello'`、`"world"` |
| `boolean` | 布尔值 | `true`、`false` |
| `undefined` | 声明未赋值时的默认值 | `let a` → `a` 为 `undefined` |
| `null` | 特殊空值 | `null` |

#### 引用数据类型

- `Array` — 数组
- `Function` — 函数
- `Object` — 对象

#### 字符串详解

```js
// 三种引号
'单引号'   "双引号"   `反引号`

// 字符串拼接（+ 号）
'hello' + 'world'   // → 'helloworld'

// 模板字符串（反引号），支持换行和插值
let name = '小明'
`你好，${name}！`   // → '你好，小明！'
```

#### 查看数据类型

```js
typeof 变量名
// 注意：typeof null 返回 'object'（历史遗留问题）
```

## 三、运算符

> **Day 05**

### 3.1 算术运算符

| 运算符 | 说明 |
|--------|------|
| `+` `-` `*` `/` | 加减乘除 |
| `%` | 取余（模运算） |

**`%` 的应用场景：**

```js
n % 2 === 0   // 判断偶数
n % 2 !== 0   // 判断奇数
n % 6 === 0   // 判断是否为 6 的倍数
```

> ⚠️ `NaN`（Not a Number）：非数字结果，参与任何运算仍为 `NaN`

### 3.2 赋值运算符

```js
=          // 基础赋值
a += b     // 等价于 a = a + b
a -= b     // 等价于 a = a - b
a *= b     // 等价于 a = a * b
a /= b     // 等价于 a = a / b
```

### 3.3 自增 / 自减运算符

```js
a++   // 后置：先用后加
++a   // 前置：先加后用
```

> 💡 实际开发中单独使用时没有区别，**推荐使用 `a++`**

### 3.4 比较运算符

| 运算符 | 说明 |
|--------|------|
| `>` `>=` `<` `<=` | 大于、大于等于、小于、小于等于 |
| `===` | 全等（值和类型都相同） |
| `!==` | 不全等 |

> 比较表达式的结果是**布尔类型**（`true` 或 `false`）

### 3.5 逻辑运算符

| 运算符 | 名称 | 规则 |
|--------|------|------|
| `&&` | 逻辑与 | 一假则假（并且关系） |
| `\|\|` | 逻辑或 | 一真则真（或者关系） |
| `!` | 逻辑非 | 取反 |

### 3.6 优先级

```
算术运算符 > 比较运算符 > 逻辑运算符
先乘除后加减 / 先与（&&）后或（||）
不确定时用 () 明确优先级
```

## 四、类型转换

> **Day 06**

### 4.1 显式转换（手动）

```js
// 其他 → 数字
Number('123')    // → 123
Number('')       // → 0
Number(true)     // → 1
parseInt('12px') // → 12（忽略非数字后缀）
parseFloat('3.14px') // → 3.14

// 其他 → 字符串
String(123)      // → '123'

// 其他 → 布尔
Boolean(0)       // → false
Boolean('')      // → false
Boolean(null)    // → false
Boolean(undefined) // → false
Boolean(NaN)     // → false
// 以上 6 个转为 false，其余全部转为 true
```

### 4.2 隐式转换（自动）

| 场景 | 转换方向 | 注意 |
|------|----------|------|
| 算术运算符 | 其他 → 数字 | `+` 两边有字符串则转字符串 |
| 比较运算符 | 其他 → 数字 | `===` 不会转换类型 |
| `+` 拼接 | 其他 → 字符串 | — |
| `!` 运算 | 其他 → 布尔 | — |

> ✅ 建议**优先使用显式转换**，避免隐式转换带来的意外结果。

## 五、流程控制语句

> **Day 06**

### 5.1 分类

| 结构 | 特点 | 语句 |
|------|------|------|
| 顺序结构 | 从上到下依次执行 | 默认 |
| 分支结构 | 根据条件选择性执行 | `if`、`switch` |
| 循环结构 | 代码可重复执行 | `for`、`while` |

### 5.2 if 语句

```js
// 格式 1
if (条件) { }

// 格式 2
if (条件) { } else { }

// 格式 3
if (条件1) { }
else if (条件2) { }
else { }
```

### 5.3 三元运算符

```js
条件 ? 值1 : 值2
// 条件成立返回值1，否则返回值2，用于简化 if-else
```

### 5.4 switch 语句

```js
switch (表达式) {
  case 值1:
    语句1
    break
  case 值2:
    语句2
    break
  default:
    语句n
}
```

**case 穿透：** 不写 `break` 时会继续执行下一个 case，直到遇到 `break` 或 switch 结束。当**多个分支执行相同操作**时可利用穿透简化代码。

**if vs switch：**

- `switch` 用于**值匹配**，执行效率更高
- `if` 用于**范围区间匹配**

### 5.5 while 循环

```js
初始化语句
while (循环条件) {
  循环体
  迭代语句
}
```

### 5.6 for 循环

```js
for (初始化语句; 循环条件; 迭代语句) {
  循环体
}
```

**while vs for：**

- `while` 多用于**循环次数未知**的情况
- `for` 多用于**循环次数已知**的情况

### 5.7 break / continue

```js
break      // 结束整个循环
continue   // 跳过本次循环，继续下次

// break 支持带标号，用于结束嵌套循环中的指定循环
loop: while (true) {
  break loop
}
```

### 5.8 死循环

```js
while (true) { }
for (;;) { }
// 套路：先写业务逻辑 → 用死循环包裹 → 写 break 出口
```

## 六、数组

> **Day 06 & 07**

### 6.1 数组基础

```js
// 定义数组
let arr = [1, 2, 3, 'hello', true]

// 访问元素（索引从 0 开始）
arr[0]   // → 1

// 获取长度
arr.length

// 遍历数组
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i])
}
```

### 6.2 数组操作方法

#### 增

```js
arr.push(数据1, 数据2)    // 在末尾添加，修改原数组
arr.unshift(数据1, 数据2) // 在开头添加，修改原数组
```

#### 删

```js
arr.pop()    // 删除最后一个，修改原数组
arr.shift()  // 删除第一个，修改原数组
```

#### 改

```js
arr[索引] = 新值   // 修改指定索引的值
```

#### 查

```js
arr[索引]   // 查询指定索引的值（索引从 0 开始）
```

#### splice（万能方法）

```js
// 新增：在起始索引处插入数据
arr.splice(起始索引, 0, 数据1, 数据2)

// 删除：从起始索引删除指定个数
arr.splice(起始索引, 要删除的个数)

// 替换：删除后插入新数据
arr.splice(起始索引, 要删除的个数, 新数据1, 新数据2)
```

### 6.3 数组排序

```js
// 升序
arr.sort((a, b) => a - b)

// 降序
arr.sort((a, b) => b - a)
```

## 七、函数

> **Day 07**

### 7.1 函数基础

函数是**将一段代码封装起来完成某一特定功能**的结构，可用于**复用代码**。

```js
// 函数定义
function 函数名(形参1, 形参2) {
  函数体
  return 返回值
}

// 函数调用
函数名(实参1, 实参2)

// 有返回值时用变量接收
let result = 函数名(实参1, 实参2)
```

### 7.2 函数参数

```js
// 形参可以设置默认值
function sum(a = 0, b = 0) {
  return a + b
}
```

| 情况 | 结果 |
|------|------|
| 实参多于形参 | 多余的实参被忽略 |
| 形参多于实参 | 多余的形参值为 `undefined` |

### 7.3 return 返回值

| 写法 | 效果 |
|------|------|
| `return 值` | 结束函数 + 返回结果 |
| `return` | 结束函数 + 返回 `undefined` |
| 不写 `return` | 函数执行完毕，返回 `undefined` |

### 7.4 逻辑运算符短路特性

在 JS 中，`&&` 和 `||` 返回的是**实际参与运算的原值**，而非单纯的 `true/false`。

| 运算符 | 短路条件 | 返回值 |
|--------|----------|--------|
| `&&` | 左边为假值时短路 | 看左边的值 |
| `\|\|` | 左边为真值时短路 | 看左边的值 |

```js
// 应用场景
let name = userInput || '默认名字'   // 用 || 设置默认值
let len = obj && obj.name.length    // 用 && 安全访问对象属性
```

## 八、对象

> **Day 08**

### 8.1 对象概述

JS 对象是一种**以键值对形式存储数据的引用类型**，用来描述某一事物。

| 组成 | 本质 | 描述内容 |
|------|------|----------|
| **属性** | 变量 | 事物的特征（名词） |
| **方法** | 函数 | 事物的行为（动词） |

```js
// 对象定义
const person = {
  name: '小明',           // 属性
  age: 18,
  say: function () {      // 方法
    console.log('hello')
  }
}
```

### 8.2 对象操作（增删改查）

```js
// 增
obj.newProp = '值'
obj.newMethod = function () {}

// 删
delete obj.propName
delete obj.methodName

// 改
obj.existProp = '新值'

// 查（两种方式）
obj.propName
obj['propName']   // 用于属性名含特殊字符或变量做键名的场景
```

### 8.3 遍历对象

```js
for (let key in obj) {
  console.log(key)       // 属性名
  console.log(obj[key])  // 属性值
}
```

### 8.4 内置对象 Math

| 属性 / 方法 | 说明 |
|-------------|------|
| `Math.PI` | 圆周率 π |
| `Math.max(a, b)` | 取最大值 |
| `Math.min(a, b)` | 取最小值 |
| `Math.abs(n)` | 取绝对值 |
| `Math.ceil(n)` | 向上取整 |
| `Math.floor(n)` | 向下取整 |
| `Math.round(n)` | 四舍五入（`-1.5` → `-1`） |
| `Math.random()` | 生成 `[0, 1)` 的随机小数 |

**生成指定范围随机整数：**

```js
// 生成 [0, 10] 的随机整数
Math.floor(Math.random() * 11)

// 生成 [5, 20] 的随机整数（减加法）
Math.floor(Math.random() * 16) + 5
```

### 8.5 变量存储机制

| 类型 | 存储内容 |
|------|----------|
| 基本类型（number / string / boolean 等） | 直接存储**数据值** |
| 引用类型（Array / Object / Function） | 存储**地址值**，数据在堆内存中 |

### 8.6 变量声明最佳实践

> 以后声明变量**优先使用 `const`**；数组和对象也**使用 `const`** 声明，防止被整体替换。
