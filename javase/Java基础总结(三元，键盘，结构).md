## 一、运算符补充

### 1.1 三元运算符

**格式：**

```java
条件表达式 ? 值1 : 值2
```

**执行流程：**

- 条件表达式**成立** → 返回 `值1`
- 条件表达式**不成立** → 返回 `值2`

```java
int a = 10, b = 20;
int max = a > b ? a : b;   // max → 20
```

### 1.2 运算符优先级

| 规则 | 说明 |
|------|------|
| 先乘除后加减 | 算术运算符基本优先级 |
| 先与（`&&`）后或（`\|\|`） | 逻辑运算符优先级 |
| **不确定时加 `()`** | 括号优先级最高，确保逻辑清晰 |

### 2.1 相关概念

### 2.2 使用 Scanner 类实现键盘录入

**实现类：** `java.util.Scanner`

**完整步骤：**

```java
import java.util.Scanner;   // 第一步：导包

public class Demo {
    public static void main(String[] args) {
        // 第二步：创建 Scanner 对象
        Scanner sc = new Scanner(System.in);

        // 第三步：友好提示
        System.out.println("请输入一个整数：");

        // 第四步：接受用户输入
        int num = sc.nextInt();       // 接受整数
        // double d = sc.nextDouble(); // 接受小数
        // String s = sc.next();      // 接受字符串
    }
}
```

### 2.3 常用接收方法

| 方法 | 作用 |
|------|------|
| `sc.nextInt()` | 接受整数 |
| `sc.nextDouble()` | 接受小数 |
| `sc.next()` | 接受字符串 |

### 2.4 导包规则

> `java.lang` 包下的类**不需要手动导包**，其他包下的类均需要 `import`。

## 三、流程控制结构概述

Java 程序有三种基本流程控制结构：

| 结构类型 | 特点 | 语句 |
|----------|------|------|
| **顺序结构** | 从上到下依次执行（默认） | 无特殊语句 |
| **分支结构** | 根据条件选择性执行 | `if`、`switch` |
| **循环结构** | 代码可以重复执行 | `for`、`while`、`do-while` |

## 四、分支结构

### 4.1 if 语句

#### 格式一：单分支

```java
if (条件表达式) {
    语句体
}
```

#### 格式二：双分支

```java
if (条件表达式) {
    语句体
} else {
    语句体
}
```

#### 格式三：多分支

```java
if (条件表达式) {
    语句体
} else if (条件表达式) {
    语句体
} else {
    语句体
}
```

---

### 4.2 switch 语句

**格式：**

```java
switch (表达式) {
    case 值1:
        语句体1
        break;
    case 值2:
        语句体2
        break;
    // ...
    default:
        语句体n
}
```

**执行流程：**

1. 先计算表达式的值
2. 拿结果与各 `case` 后的值进行匹配（**不是从上到下顺序匹配**）
3. 执行匹配成功的语句体，然后执行 `break` 结束 switch

**注意事项：**

| 注意点 | 说明 |
|--------|------|
| 不支持 `float`、`double` | 小数在计算机中存储不精确，无法准确匹配 |
| 不支持 `long` | 范围过大，`int` 已足够使用 |
| `case` 后的值必须是**字面量** | 不能是变量，且不能重复 |
| 不写 `break` | 可能出现 **case 穿透**现象，继续执行下一个 case |

---

### 4.3 if vs switch 对比

| 对比项 | `if` | `switch` |
|--------|------|----------|
| 功能 | 更强，支持范围判断 | 专注于值的精确匹配 |
| 适用场景 | **范围区间判断** | **固定值匹配** |

## 五、循环结构

### 5.1 for 语句

**语法：**

```java
for (初始化语句; 循环条件语句; 循环迭代语句) {
    循环体语句
}
```

**执行流程：**

```
① 执行初始化语句（只执行一次）
② 判断循环条件 → 成立则执行循环体
③ 执行循环迭代语句
④ 返回 ② 继续判断，直到条件不成立 → 循环结束
```

---

### 5.2 while 语句

**语法：**

```java
初始化语句;
while (循环条件语句) {
    循环体语句;
    循环迭代语句;
}
```

> 执行流程与 `for` 相同，先判断再执行。

---

### 5.3 do-while 语句

**语法：**

```java
初始化语句;
do {
    循环体语句;
    循环迭代语句;
} while (循环条件语句);
```

> ⚠️ `do-while` **先执行后判断**，循环体**至少执行一次**。

---

### 5.4 三种循环对比

| 对比项 | `for` | `while` | `do-while` |
|--------|-------|---------|------------|
| 先判断再执行 | ✅ | ✅ | ❌ |
| 先执行再判断 | ❌ | ❌ | ✅（至少执行一次） |
| 适用场景 | **循环次数已知** | **循环次数未知** | 需至少执行一次时 |
| 可互相替换 | `for` ↔ `while` 可替换 | — | — |

---

### 5.5 死循环

三种循环语句都可以写死循环，**推荐使用 `while(true)`**。

```java
while (true) {
    // 业务逻辑
    if (退出条件) {
        break;
    }
}
```

**写死循环的套路：**

1. 先写一遍完整业务逻辑
2. 用 `while(true)` 包裹需要重复执行的代码（快捷键：`Ctrl + Alt + T` → 选择 `while`）
3. 写出口条件，使用 `break` 退出

---

### 5.6 循环嵌套

**定义：** 循环中套循环，外面的叫**外循环**，里面的叫**内循环**。

**执行特点：**

```
外循环执行 1 次  →  内循环执行 1 轮（完整的从头到尾）
```

**使用场景与规律：**

| 规律 | 说明 |
|------|------|
| 多用于打印**二维数据** | 如乘法表、图形 |
| 外循环次数 | 与**行数**有关 |
| 内循环次数 | 与**列数**有关 |
| 实际最多嵌套 | **两层**，避免逻辑复杂 |

```java
// 示例：打印 3 行 4 列的星号
for (int i = 0; i < 3; i++) {          // 外循环控制行
    for (int j = 0; j < 4; j++) {      // 内循环控制列
        System.out.print("* ");
    }
    System.out.println();
}
```

---

### 5.7 break 与 continue

| 关键字 | 作用 | 适用范围 |
|--------|------|----------|
| `break` | **结束整个循环** | 循环、switch |
| `continue` | **跳过本次循环**，继续执行下次 | 循环 |

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) continue;   // 跳过 i=5 这次
    if (i == 8) break;      // 到 i=8 时结束整个循环
    System.out.println(i);  // 输出：1 2 3 4 6 7
}
```

## 六、随机数

### 6.1 使用 Random 类生成随机数

**实现类：** `java.util.Random`

**步骤：**

```java
import java.util.Random;

Random r = new Random();         // 第一步：创建 Random 对象
int num = r.nextInt(10);         // 第二步：生成随机数（0 ~ 9）
```

> `nextInt(n)` 生成范围：**`[0, n-1]`**（包含 0，不包含 n）

---

### 6.2 生成指定范围的随机数（减加法）

**需求：** 生成 `[a, b]` 之间的随机整数

**思路（减加法）：**

```
① 先减去 a，让范围变成从 0 开始：范围变为 [0, b-a]
② 推导 nextInt 的参数：nextInt(b - a + 1)
③ 再加上 a 还原偏移量
```

**公式：**

```java
int result = r.nextInt(b - a + 1) + a;
```

**示例：生成 `[5, 20]` 之间的随机整数**

```java
// ① 5 到 20，先减 5 → 范围变为 [0, 15]
// ② nextInt(16) 生成 [0, 15]
// ③ 再加 5 → [5, 20]
int result = r.nextInt(16) + 5;
```
