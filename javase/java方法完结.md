## 一、方法定义的四种形式

根据**有无参数**与**有无返回值**，方法定义可分为四类：

| 类型 | 格式示例 | 说明 |
|------|----------|------|
| 无参数、无返回值 | `public static void show()` | 最简单的形式 |
| 有参数、无返回值 | `public static void print(int n)` | 需要数据但不返回结果 |
| 无参数、有返回值 | `public static int getNum()` | 不需要外部数据，返回结果 |
| 有参数、有返回值 | `public static int add(int a, int b)` | 既需要数据又返回结果 |

### 示例代码

```java
// ① 无参数、无返回值
public static void sayHello() {
    System.out.println("Hello!");
}

// ② 有参数、无返回值
public static void printNum(int n) {
    System.out.println("数字是：" + n);
}

// ③ 无参数、有返回值
public static int getFixed() {
    return 100;
}

// ④ 有参数、有返回值
public static int add(int a, int b) {
    return a + b;
}
```

### 总结

| 情况 | 写法要点 |
|------|----------|
| 方法**没有返回值** | 返回值类型写 `void`，方法体中**不要用 `return` 返回结果** |
| 方法**没有参数** | 形参列表**留空**，调用时也无需传递实参 |

## 二、方法使用注意事项

| 注意事项 | 说明 |
|----------|------|
| **定义位置** | 方法写在**类中方法外**，方法之间是**平级关系**，书写顺序不影响执行 |
| **形参与实参一致** | 数量、类型、类型顺序必须**严格一致** |
| **有返回值的方法** | 建议使用**变量接收**返回值 |
| **无返回值的方法** | 只能**直接调用**，不能用变量接收 |

```java
// ✅ 正确：有返回值用变量接收
int result = add(3, 5);

// ✅ 正确：无返回值直接调用
sayHello();

// ❌ 错误：类型不匹配
// add(3.14, "hello");  // 参数类型不符
```

## 三、方法调用内存分析

### 3.1 调用运行位置

方法调用在**栈内存（Stack）** 中运行。

### 3.2 栈内存特点

> 栈内存遵循 **"先进后出"** 的原则。

```
调用顺序：main → methodA → methodB
出栈顺序：methodB 先出 → methodA 再出 → main 最后出
```

### 3.3 执行流程图

```
┌─────────────┐
│  methodB()  │  ← 最后进栈，最先出栈
├─────────────┤
│  methodA()  │
├─────────────┤
│   main()    │  ← 最先进栈，最后出栈
└─────────────┘
       栈（先进后出）
```

> 💡 每个方法调用时都会在栈中开辟一块独立空间（**栈帧**），方法执行完毕后该空间立即释放。

## 四、方法参数传递机制

### 4.1 Java 的参数传递方式

Java 语言中，参数传递机制只有一种：**值传递（Pass by Value）**

> **值传递：** 将实参的**副本**传递给形参，方法内对形参的修改**不影响**原来的实参。

### 4.2 基本数据类型 vs 引用数据类型

| 参数类型 | 传递的内容 | 方法内修改形参 | 是否影响原始数据 |
|----------|------------|---------------|-----------------|
| **基本数据类型** | 传递**数据值**的副本 | 只修改副本 | ❌ 不影响 |
| **引用数据类型** | 传递**地址值**的副本 | 通过地址修改堆中的对象 | ✅ 会影响 |

### 4.3 代码示例

```java
// 基本类型：不影响原始数据
public static void changeInt(int n) {
    n = 100;   // 只修改了副本
}
int x = 10;
changeInt(x);
System.out.println(x);   // → 10（未受影响）

// 引用类型：会影响原始数据
public static void changeArr(int[] arr) {
    arr[0] = 999;   // 通过地址修改了堆中的数组
}
int[] nums = {1, 2, 3};
changeArr(nums);
System.out.println(nums[0]);   // → 999（已被修改）
```

## 五、方法重载

### 5.1 什么是方法重载

方法之间的一种关系：要求多个方法在**同一个类**中，且**方法名相同、形参列表不同**。

### 5.2 判断方法重载的口诀

> **"2 同 3 不同 3 无关"**

| 类别 | 条件 | 说明 |
|------|------|------|
| **2 同** | 同一个类 | 必须在同一个类中 |
| | 方法名相同 | 方法名必须一致 |
| **3 不同** | 形参**个数**不同 | 满足其一即可构成重载 |
| | 形参**类型**不同 | — |
| | 形参**顺序**不同 | — |
| **3 无关** | 与**修饰符**无关 | 不影响重载判断 |
| | 与**返回值类型**无关 | — |
| | 与**形参名称**无关 | — |

### 5.3 重载示例

```java
// 以下三个方法构成重载关系（同类、同名、形参列表不同）
public static int add(int a, int b) {
    return a + b;
}

public static double add(double a, double b) {
    return a + b;
}

public static int add(int a, int b, int c) {
    return a + b + c;
}
```

### 5.4 应用场景

> 方法重载适用于**同一类业务有不同处理方案**的场景，使方法命名更统一、调用更直观。

## 六、return 关键字

### 6.1 两大作用

| 作用 | 说明 |
|------|------|
| ① **结束方法** | 方法执行到 `return` 时立即终止，后续代码不再执行 |
| ② **返回结果** | 将结果值返回给方法的调用者 |

### 6.2 两种用法

#### 用法一：返回结果（有返回值方法）

```java
public static int max(int a, int b) {
    if (a > b) {
        return a;   // 结束方法 + 返回 a
    }
    return b;       // 结束方法 + 返回 b
}
```

#### 用法二：单独使用（`void` 方法）

```java
// return; 只能用在 void 方法中，用于提前结束方法
public static void printPositive(int n) {
    if (n <= 0) {
        return;   // 提前结束，不再执行后续代码
    }
    System.out.println("正数：" + n);
}
```

### 6.3 总结

| 方法类型 | `return` 写法 | 说明 |
|----------|---------------|------|
| 有返回值方法 | `return 结果;` | 必须写，且类型须与返回值类型匹配 |
| `void` 方法 | `return;`（可选） | 单独使用，仅用于提前结束方法 |
| `void` 方法 | 不写 `return` | 方法体执行完毕后自动结束 |
