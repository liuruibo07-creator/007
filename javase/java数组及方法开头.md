## 一、数组概述

数组是一种**容器**，用于存储**多个相同类型**的数据。

---

## 二、数组初始化

### 2.1 静态初始化

**适用场景：** 已知元素值

**格式：**

```java
// 完整格式
数据类型[] 数组名 = new 数据类型[]{元素1, 元素2, ...};

// 简化格式（推荐）
数据类型[] 数组名 = {元素1, 元素2, ...};
```

**示例：**

```java
int[] ages = {18, 20, 25, 30};
String[] names = {"Alice", "Bob", "Charlie"};
```

> 💡 静态初始化**推荐使用简化格式**，代码更简洁。

---

### 2.2 动态初始化

**适用场景：** 元素值未知，但知道数组长度

**格式：**

```java
数据类型[] 数组名 = new 数据类型[长度];
```

**示例：**

```java
int[] scores = new int[5];   // 创建长度为 5 的整数数组
```

**各类型默认值：**

| 数据类型 | 默认值 |
|----------|--------|
| 整数（`byte` `short` `int` `long`） | `0` |
| 小数（`float` `double`） | `0.0` |
| 布尔（`boolean`） | `false` |
| 字符（`char`） | `'\u0000'`（值为 0） |
| 引用类型（数组、对象等） | `null` |

> 💡 动态初始化完成后，**先不做其他操作，优先考虑赋值**，常见套路：一边遍历，一边赋值。

---

### 2.3 两种初始化方式对比

| 对比项 | 静态初始化 | 动态初始化 |
|--------|------------|------------|
| 是否已知元素值 | ✅ 已知 | ❌ 未知 |
| 长度 | 由元素个数自动决定 | 手动指定 |
| 默认值 | 即为指定的元素值 | 由数据类型决定 |

## 三、数组访问与遍历

### 3.1 访问单个元素

```java
数组名[索引]
```

**索引规则：**

- 从 **`0`** 开始
- 最大索引为 **`数组.length - 1`**

```java
int[] arr = {10, 20, 30, 40};
System.out.println(arr[0]);   // → 10
System.out.println(arr[3]);   // → 40（最大索引）
```

### 3.2 遍历数组

```java
// 快捷键：数组名.fori  快速生成 for 循环
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

### 3.3 数组索引越界异常

当访问的索引**超出合法范围**时，程序抛出：

```
ArrayIndexOutOfBoundsException（数组索引越界异常）
```

## 四、数组打印

| 数组类型 | 直接打印结果 | 原因 |
|----------|-------------|------|
| 普通数组（如 `int[]`） | 打印**地址值** | 数组是引用数据类型 |
| 字符数组（`char[]`） | 打印**元素内容** | `println` 对 `char[]` 有特殊处理 |

```java
int[] arr = {1, 2, 3};
char[] chars = {'a', 'b', 'c'};

System.out.println(arr);    // → [I@6d06d69c（地址值）
System.out.println(chars);  // → abc（元素内容）
```

## 五、JVM 内存分析

### 5.1 JVM 内存区域划分

| 内存区域 | 作用 |
|----------|------|
| **方法区** | 存放**字节码文件**（`.class` 文件） |
| **栈**（Stack） | 方法运行的环境，存放**局部变量**（方法内的变量和形参） |
| **堆**（Heap） | 存放所有 `new` 出来的**数组和对象**，每个都有地址值 |
| 本地方法栈 | 执行本地（Native）方法 |
| 程序计数器 | 记录当前线程执行到哪一行 |

### 5.2 单个数组的内存执行流程

```
① 将磁盘中的字节码文件加载进内存中的方法区
② JVM 调用 main 方法
③ main 方法进入栈内存中运行
④ 若方法中有局部变量，在栈内存中开辟空间存储
⑤ 在堆内存中开辟连续空间（每个元素大小相同），数组变量存储该空间的地址值
```

### 5.3 多个数组的内存图

> `new` 了几次，堆内存中就会有**几个独立的数组对象**。

```java
int[] a = new int[3];   // 堆中创建一个数组
int[] b = new int[3];   // 堆中再创建另一个数组
// a 和 b 指向不同的地址
```

### 5.4 多个变量指向同一数组

```java
int[] a = {1, 2, 3};
int[] b = a;            // b 与 a 存储相同的地址值

b[0] = 100;
System.out.println(a[0]);  // → 100（a 也能看到修改）
```

> **核心规律：** 多个变量存储相同的地址值时，任意一方修改数组内容，其他变量都能观察到变化。

### 5.5 空指针异常

```java
int[] arr = null;
System.out.println(arr[0]);  // ❌ NullPointerException（NPE）
```

**触发条件：** 数组（或对象）变量值为 `null` 时，仍然访问其元素或属性。

## 六、方法

### 6.1 概述

方法是一种**语法结构**，将一段代码封装起来完成某一功能，并且可以**复用**。

### 6.2 方法定义

**格式：**

```java
修饰符  返回值类型  方法名(形参列表) {
    方法体
    return 返回结果;
}
```

**示例：**

```java
public static int add(int a, int b) {
    return a + b;
}
```

**定义要点：**

| 要点 | 说明 |
|------|------|
| 书写位置 | **类中方法外** |
| 当前修饰符 | 固定写法：`public static` |
| 是否有返回值 | 站在**方法调用者**的角度考虑是否需要结果 |
| 是否有形参 | 完成这个功能，缺少什么数据就定义几个形参 |

### 6.3 方法调用

**格式：**

```java
方法名(实参列表);

// 有返回值时，推荐用变量接收
返回值类型 变量名 = 方法名(实参列表);
```

**调用执行流程：**

```
第一步：参数传递 → 实参的值传递给形参
第二步：执行方法体
第三步：执行完毕后回到调用处，继续向下执行
```

**示例：**

```java
int result = add(10, 20);   // result → 30
```

## 七、IDEA 调试（Debug）

### 7.1 常用调试按钮说明

| 按钮图标含义 | 功能说明 | 使用频率 |
|-------------|----------|----------|
| **步过**（Step Over） | 遇到方法时**不进入方法体**，直接执行到下一行 | ⭐ 最高，最常用 |
| **步入**（Step Into） | 遇到方法时**进入方法体**内部，查看方法执行过程 | 仅需查看方法内部时使用 |
| **步出**（Step Out） | 从当前方法体中**跳出来**，回到调用处 | 进入方法后想快速退出时使用 |
| **跳至下一断点**（Resume） | 跳到下一个断点；若已是最后一个断点，则将程序**运行至结束** | 多断点调试时使用 |
| **查看所有断点** | 展示当前所有断点，支持**批量删除** | 断点过多时整理用 |
| **禁用所有断点** | 使所有断点**暂时失效**，不影响正常运行 | 临时关闭调试时使用 |

### 7.2 Debug 使用建议

> 🔍 调试时**优先使用"步过"按钮**，只有在确实需要查看某个方法的内部逻辑时，才使用"步入"进入方法体。
