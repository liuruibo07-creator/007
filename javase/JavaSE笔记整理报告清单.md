# JavaSE 笔记整理报告清单

## 一、整理概况

- **笔记数量**：19 份（不含本报告）
- **内容范围**：Java 基础语法、数组与方法、面向对象、常用 API、集合、异常与函数式编程、文件与 IO、配置与测试、多线程、线程池及网络编程。
- **整体结构**：笔记大体按照 Day19—Day37 的学习进度排列，知识由“基础语法”逐步过渡到“面向对象”，再进入“Java 常用类与集合”“IO 与工程工具”，最后学习“并发与网络”。
- **建议用途**：可以把本清单作为总目录、复习索引和查漏补缺清单使用。

## 四、文件之间的关键横向联系

### 1. 语法与程序结构主线

- 变量、数据类型、运算符是所有代码的最小基础。
- 分支和循环用于控制执行流程，随后应用于数组遍历、排序、查找、集合遍历和业务判断。
- 方法把代码封装成可复用单元；类和对象进一步把数据与方法组织为完整模型。

### 2. 面向对象主线

- Day22 的**封装**解决对象内部数据的保护问题。
- Day24—25 的**继承与重写**解决共性代码复用问题。
- Day25 的**多态**让程序可以用父类或接口统一接收不同实现。
- Day25—26 的**抽象类与接口**规定共同能力与行为标准。
- 这些概念共同解释集合体系、IO 包装流、线程任务接口及 Lambda 的设计方式。

### 3. 字符串、泛型与集合主线

- Day23 从 `String` 和 `ArrayList` 入门常用 API 与集合。
- Day27 的包装类解决“基本类型不能直接作为泛型参数”的问题，泛型为集合提供类型安全。
- Day30 扩展单列集合，Day31 补充双列 `Map` 和 `Collections` 工具类。
- Day29 的 Lambda/方法引用与 Day32 的 Stream 共同提供更简洁的数据处理方式。

### 4. 数组与算法主线

- Day20 介绍数组存储和遍历。
- Day28 使用 `Arrays` 完成打印、复制和排序。
- Day29 一方面继续使用 `Arrays.sort/binarySearch`，另一方面手写排序、查找算法以理解底层思路。
- 二分查找的必要前提是数据已经有序，应与排序内容一起复习。

### 5. 文件与 IO 主线

- Day32：`File` 管理文件/目录路径，字节流开始真正读文件。
- Day33：补齐输出流、字符流、缓冲流、转换流以及资源释放。
- Day34—35：用 IO 读写 Properties/XML，并通过配置文件驱动日志框架。
- 字符集决定字节和字符如何转换，异常处理保证文件操作失败时能够正确处理和释放资源。

### 6. 并发与网络主线

- Day36 先讲线程创建、同步、死锁和线程通信。
- Day37 用线程池集中管理线程，补充生命周期、并发与并行，再进入 UDP 网络通信。
- 网络程序通常还会结合 IO、异常、线程池和日志，是前面多条知识线的综合应用。
