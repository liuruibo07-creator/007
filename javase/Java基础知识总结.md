## 一、IDEA 常用操作

### 1.1 删除 / 移出模块

| 操作 | 效果 |
|------|------|
| `Remove`（移出） | 将模块从 IDEA 项目中移除，变成普通文件夹，**磁盘上仍保留** |
| `Delete`（删除） | 从**磁盘上彻底删除**文件夹 |

### 1.2 导入模块

1. 将模块文件夹**复制**到项目文件夹下
2. 打开 `项目结构` → `模块` 选项 → 点击`导入模块`
3. 选中对应的 `xxx.iml` 文件即可

### 1.3 新建空项目后的配置

- 配置 **JDK**
- 配置**语言版本**（SDK Default）

## 二、注释

### 2.1 什么是注释

对代码进行**解释说明**的文字，只存在于源文件中，**不影响代码功能**。

### 2.2 注释类型

| 类型 | 语法 | 特点 |
|------|------|------|
| **单行注释** | `// 注释内容` | 只能写一行 |
| **多行注释** | `/* 注释内容 */` | 可以写多行 |
| **文档注释** | `/** 注释内容 */` | 可以写多行，用于生成 API 文档 |

### 2.3 使用场景与快捷键

| 场景 | 建议 | 快捷键 |
|------|------|--------|
| 给代码加文字说明 | 写在代码上方，手动书写 | — |
| 注释代码使其不生效（单行） | 使用快捷键 | `Ctrl + /` |
| 注释代码使其不生效（多行） | 使用快捷键 | `Ctrl + Shift + /` |

## 三、字面量

### 3.1 什么是字面量

**数据在代码中的书写格式**。

### 3.2 字面量分类

| 类型 | 书写格式 | 示例 |
|------|----------|------|
| 整数 | 与生活中一致 | `18` |
| 小数 | 与生活中一致 | `1.85` |
| 字符 | 单引号，**有且只能写一个字符** | `'a'` |
| 字符串 | 双引号，内容可有可无 | `"张三"` |
| 布尔 | `true` / `false` | `true` |
| 空 | — | `null` |

### 3.3 特殊字符

| 转义字符 | 含义 |
|----------|------|
| `\n` | 换行 |
| `\t` | 缩进（多个空格） |

## 四、变量

### 4.1 什么是变量

变量是一个**容器**，可以存储一个数据，且存储的数据可以发生变化。

**本质**：内存中的一块空间（任何程序都在内存中运行）。

### 4.2 定义格式

```java
数据类型  变量名 = 数据值;

// 同行定义多个变量（要求类型相同）
int x = 10, y = 20, z = 30;
```

### 4.3 变量的使用方式

- 打印输出
- 参与运算
- 修改变量的值

### 4.4 应用场景

| 场景 | 说明 |
|------|------|
| 数据被**多次重复使用** | 用变量存储，避免重复书写 |
| 数据**经常发生改变** | 用变量存储，便于统一修改 |

### 4.5 注意事项

1. 变量在**使用前必须有值**
2. 变量有**作用域**（使用范围）——离变量定义最近的一对 `{}` 即为其作用域
3. **同一作用域**内变量不能同名
4. 同行定义多个变量时，所有变量须为**相同数据类型**

## 五、关键字与标识符

### 5.1 关键字

具有**特殊含义**的英文单词（如 `class`、`int`、`public`）。

**特点：**
- 全部**小写**
- 在 IDEA 中会**高亮显示**

### 5.2 标识符

给**类、变量、方法**取的名字。

#### 硬性要求（必须遵守）

| 规则 | 说明 |
|------|------|
| 组成字符 | 数字、字母、`_`、`$`、中文 |
| 不能以数字开头 | — |
| 不能与关键字同名 | — |
| 区分大小写 | `name` 和 `Name` 是不同标识符 |

#### 软性建议（规范遵守）

| 规范 | 适用对象 | 示例 |
|------|----------|------|
| **小驼峰**：第一个单词首字母小写，后续每个单词首字母大写 | 变量、方法 | `myName`、`getUserInfo` |
| **大驼峰**：每个单词首字母都大写 | 类 | `MyClass`、`StudentInfo` |
| **见名知意** | 所有标识符 | `age` 而非 `a` |

## 六、进制与编码

### 6.1 常见进制对照

| 进制 | 组成 | 特点 | Java 中书写前缀 |
|------|------|------|-----------------|
| 二进制 | `0`、`1` | 逢二进一，借一当二 | `0b`（如 `0b1010`） |
| 八进制 | `0` ~ `7` | 逢八进一，借一当八 | `0`（如 `017`） |
| 十进制 | `0` ~ `9` | 逢十进一，借一当十 | 默认，无前缀 |
| 十六进制 | `0`~`9`、`a`~`f` | 逢十六进一，借一当十六 | `0x`（如 `0xFF`） |

### 6.2 进制转换方法

```
十进制 → 二进制：除 2 取余，直到商为 0，余数倒排
二进制 → 十进制：8421 码（权位相加）
二进制 → 八进制 ：三位分组，每组用 8421 码转十进制后拼接
二进制 → 十六进制：四位分组，每组用 8421 码转十进制后拼接
```

### 6.3 计算机存储单位

```
1 T  = 1024 GB
1 GB = 1024 MB
1 MB = 1024 KB
1 KB = 1024 B（字节）
1 B  = 8 bit（位）
```

> 计算机存储的**基本单位是字节（Byte，简称 B）**。

### 6.4 ASCII 编码表

字符在计算机中通过**查编码表**转换为二进制存储。

| 字符 | 对应十进制值 |
|------|-------------|
| `'a'` | 97 |
| `'A'` | 65 |
| `'0'` | 48 |

## 七、数据类型

### 7.1 Java 数据类型分类

```
Java 数据类型
├── 基本数据类型（4 类 8 种）
└── 引用数据类型（数组、类、接口）
```

### 7.2 基本数据类型（4 类 8 种）

| 大类 | 类型 | 占用字节 | 取值范围 |
|------|------|----------|----------|
| **整数** | `byte` | 1 字节 | −128 ~ 127 |
| | `short` | 2 字节 | ±3 万 |
| | `int` | 4 字节 | ±21 亿（±10 位数） |
| | `long` | 8 字节 | ±19 位数 |
| **小数** | `float` | 4 字节 | — |
| | `double` | 8 字节 | — |
| **字符** | `char` | 2 字节 | — |
| **布尔** | `boolean` | 1 字节 | `true` / `false` |

### 7.3 使用总结

| 场景 | 建议 |
|------|------|
| 未明确整数类型 | 使用 `int` |
| 未明确小数类型 | 使用 `double` |
| 定义 `float` 变量 | 字面量后加 `F`，如 `3.14F` |
| 定义 `long` 变量 | 字面量后加 `L`，如 `100L` |
| 字面量默认类型 | `10` 默认 `int`，`3.4` 默认 `double` |

## 八、类型转换

### 8.1 为什么要类型转换

Java 要求**相同类型**才能进行运算，不同类型需先转换。

### 8.2 转换分类

#### 自动类型转换（小 → 大，自动完成）

```java
int a = 10;
double b = a;  // int 自动转换为 double
```

**提升规则：**

| 规则 | 说明 |
|------|------|
| 默认规则 | 小类型与大类型运算，小类型自动提升为大类型 |
| 特殊规则 | `byte`、`short`、`char` 参与运算时，先提升为 `int` |

**取值范围大小顺序（从小到大）：**

```
byte → short → int → long → float → double
```

#### 强制类型转换（大 → 小，需手动编写）

```java
double d = 3.99;
int i = (int) d;   // → 3，直接截断小数部分（非四舍五入）
```

> ⚠️ 强制类型转换**可能造成数据溢出或精度丢失**，谨慎使用。  
> 快捷键：`Alt + Enter` 可快速生成强制转换代码。

## 九、运算符

### 9.1 算术运算符

| 运算符 | 说明 | 注意 |
|--------|------|------|
| `+` `-` `*` `/` `%` | 加减乘除取余 | — |
| `/` | 两个整数相除，结果**仍是整数**（截断小数） | `7 / 2 → 3` |
| `%` | 取余 | 判断奇偶、判断整除关系 |
| `+` | 加法 / **字符串拼接** / 正负号 | 两边出现字符串时变为拼接 |

### 9.2 自增 / 自减运算符

```java
a++   // 后置：先用当前值，再加 1
++a   // 前置：先加 1，再使用
a--   // 后置自减
--a   // 前置自减
```

| 使用方式 | 说明 |
|----------|------|
| **单独使用** | 前置后置没有区别 |
| **参与运算** | 前置先加后用；后置先用后加 |

> 💡 **建议单独使用**，避免参与运算时引起混乱。

### 9.3 赋值运算符

| 运算符 | 等价写法 | 说明 |
|--------|----------|------|
| `=` | — | 基本赋值 |
| `a += b` | `a = (a的类型)(a + b)` | 加后赋值，含隐式强制转换 |
| `a -= b` | `a = (a的类型)(a - b)` | — |
| `a *= b` | `a = (a的类型)(a * b)` | — |
| `a /= b` | `a = (a的类型)(a / b)` | — |

### 9.4 关系运算符

| 运算符 | 含义 |
|--------|------|
| `>` `>=` `<` `<=` | 大于、大于等于、小于、小于等于 |
| `==` | **比较**是否相等（区别于 `=` 赋值） |
| `!=` | 不等于 |

> 结果为**布尔类型**（`true` 或 `false`）

### 9.5 逻辑运算符

将多个小条件连接为一个大条件，结果仍为**布尔类型**。

| 类型 | 运算符 | 规则 | 说明 |
|------|--------|------|------|
| **与** | `&` | 两边都为 `true` 才为 `true` | 两边都执行 |
| **短路与** | `&&` | 同上 | 左边为 `false` 时，右边**不执行** ✅ 推荐 |
| **或** | `\|` | 两边都为 `false` 才为 `false` | 两边都执行 |
| **短路或** | `\|\|` | 同上 | 左边为 `true` 时，右边**不执行** ✅ 推荐 |
| **非** | `!` | 取反 | `!true → false` |
| **异或** | `^` | 相同为 `false`，不同为 `true` | — |
