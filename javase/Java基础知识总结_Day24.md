## 二、static 关键字

### 2.1 是什么

`static` 是一个**修饰符**，可以用来修饰**成员变量**和**成员方法**。

---

### 2.2 静态成员变量 vs 实例成员变量

| 对比项 | 静态成员变量（`static` 修饰） | 实例成员变量（无 `static`） |
|--------|-------------------------------|---------------------------|
| **归属** | 属于**类**，被所有对象共享 | 属于**对象**，每个对象有自己的一份 |
| **内存位置** | 堆内存中的**静态区** | 堆内存中（随对象存在） |
| **加载时机** | 随**类的加载**而加载 | 随**对象的创建**而存在 |
| **访问方式** | `类名.静态成员变量`（推荐）或 `对象名.变量` | 只能通过 `对象名.变量` |
| **内存份数** | 只有**一份** | 每个对象**各一份** |

**访问示例：**

```java
public class Student {
    static String school = "黑马程序员";  // 静态成员变量
    String name;                           // 实例成员变量
}

// 访问静态成员变量
System.out.println(Student.school);   // ✅ 推荐：类名访问
Student s = new Student();
System.out.println(s.school);         // 了解：对象名访问（不推荐）

// 访问实例成员变量
System.out.println(s.name);           // 只能通过对象访问
```

> 💡 **细节：** 静态成员变量在**当前类**内使用时，可省略类名；在**外部类**中不能省略。

---

### 2.3 静态成员方法 vs 实例成员方法

| 对比项 | 静态成员方法（`static` 修饰） | 实例成员方法（无 `static`） |
|--------|-------------------------------|---------------------------|
| **访问方式** | `类名.方法名()`（推荐）或 `对象名.方法名()` | 只能通过 `对象名.方法名()` |
| **能访问的成员** | 只能访问**静态成员**（变量和方法） | 可以访问**所有成员**（静态 + 实例） |
| **能否使用 `this`** | ❌ **不能**使用 `this` | ✅ 可以使用 `this` |

```java
public class MathUtil {
    // 静态方法：不能用 this，不能访问实例成员
    public static int add(int a, int b) {
        return a + b;
    }
}

// 调用（推荐类名访问）
int result = MathUtil.add(3, 5);   // → 8
```

## 三、工具类

### 3.1 什么是工具类

**工具类**是一种特殊的 Java 类，**不用来描述某一类事物**，主要通过调用方法来完成特定功能（如数学计算、字符串处理等）。

### 3.2 工具类的标准写法

```java
public class ArrayUtil {       // ① 命名规范：XXXUtil

    // ② 私有化构造方法（防止外界创建对象，工具类不需要实例）
    private ArrayUtil() {}

    // ③ 所有方法用 static 修饰（方便直接通过类名调用）
    public static int getMax(int[] arr) {
        int max = arr[0];
        for (int num : arr) {
            if (num > max) max = num;
        }
        return max;
    }

    public static void printArray(int[] arr) {
        System.out.println(Arrays.toString(arr));
    }
}

// 使用工具类
int max = ArrayUtil.getMax(new int[]{3, 1, 7, 2});   // → 7
```

### 3.3 工具类的三要素

| 要素 | 说明 |
|------|------|
| 命名以 `Util` 结尾 | 如 `StringUtil`、`DateUtil`、`FileUtil` |
| 私有化构造方法 | 防止外部 `new` 出对象 |
| 方法全部用 `static` 修饰 | 无需创建对象即可调用 |

## 四、设计模式与单例模式

### 4.1 什么是设计模式

**设计模式**是前人针对某一类问题经验总结出的**最优解决方案**，是解决特定问题的代码模板。

> 学设计模式需要掌握两点：
> 1. 这个模式解决**什么问题**
> 2. 这个模式的代码**怎么写**

---

### 4.2 单例设计模式

**目的：** 确保一个类**只有一个对象**（如系统配置类、数据库连接池等场景）。

---

#### 写法一：饿汉式（提前创建好对象）

**特点：** 类加载时就创建对象，线程安全，但可能造成资源浪费（未使用也占内存）。

```java
// 国王类：一个国家只有一个国王
public class King {

    // ① 私有化构造方法，防止外界创建对象
    private King() {}

    // ② 定义静态成员变量，存储该类唯一的对象（直接创建）
    private static King instance = new King();

    // ③ 提供 public static 方法，返回唯一对象
    public static King getInstance() {
        return instance;
    }
}

// 使用
King k1 = King.getInstance();
King k2 = King.getInstance();
System.out.println(k1 == k2);  // → true（同一个对象）
```

---

#### 写法二：懒汉式（用的时候才创建对象）

**特点：** 第一次调用时才创建，节省资源，但需注意多线程安全问题。

```java
// 皇后类：一个国家只有一个皇后
public class Queen {

    // ① 私有化构造方法
    private Queen() {}

    // ② 定义静态成员变量（不直接赋值，初始为 null）
    private static Queen instance;

    // ③ 提供 public static 方法，用的时候才创建
    public static Queen getInstance() {
        if (instance == null) {
            instance = new Queen();   // 第一次调用时创建
        }
        return instance;
    }
}
```

---

#### 饿汉式 vs 懒汉式对比

| 对比项 | 饿汉式 | 懒汉式 |
|--------|--------|--------|
| 对象创建时机 | 类加载时立即创建 | 第一次调用时才创建 |
| 内存占用 | 始终占用（可能浪费） | 按需占用（更节省） |
| 线程安全 | ✅ 天然安全 | ⚠️ 多线程需额外处理 |
| 实现难度 | 简单 | 略复杂 |

---

### 4.3 单例模式三步口诀

```
① 私有化构造方法         → 防止外界 new 对象
② 定义私有静态成员变量    → 存储唯一的对象
③ 提供公有静态方法        → 返回唯一对象（方法名固定为 getInstance）
```

## 五、继承

### 5.1 什么是继承

**继承**是**面向对象三大特征之一**，描述的是类与类之间的**父子关系**。

> 一旦建立了父子关系，**子类就可以使用父类中的非私有成员**。

### 5.2 继承的好处

> **提高代码的复用性** —— 将多个类的共同内容提取到父类中，子类无需重复定义。

### 5.3 什么时候使用继承

> 当类与类之间**有共性内容**，且**子类是父类的一种**时，考虑使用继承。

```
✅ 正确示例：猫 extends 动物     （猫是动物的一种）
✅ 正确示例：学生 extends 人     （学生是人的一种）
❌ 错误示例：汽车 extends 发动机 （汽车不是发动机的一种）
```

### 5.4 继承的分析与书写方向

```
分析：从下向上（先看子类，找共性，抽取到父类）
书写：从上向下（先写父类，再写子类 extends 父类）
```

### 5.5 继承的代码写法

```java
// 父类
public class Animal {
    String name;
    int age;

    public void eat() {
        System.out.println(name + "在吃东西");
    }
}

// 子类（继承父类，使用 extends 关键字）
public class Dog extends Animal {
    public void bark() {
        System.out.println(name + "在汪汪叫");  // 可直接使用父类的 name
    }
}

// 使用
Dog d = new Dog();
d.name = "旺财";
d.eat();    // 调用继承自父类的方法
d.bark();   // 调用子类自己的方法
```

## 六、权限修饰符

权限修饰符用于控制类、成员变量、成员方法的**访问范围**。

### 权限大小顺序

```
private  <  缺省（default）  <  protected  <  public
  最小                                          最大
```

### 各修饰符访问范围详表

![权限修饰符访问范围](access_modifiers.png)

| 修饰符 | 本类中 | 同包其他类 | 不同包的子类 | 任意类 |
|--------|:------:|:----------:|:------------:|:------:|
| `private` | ✅ | — | — | — |
| 缺省（default） | ✅ | ✅ | — | — |
| `protected` | ✅ | ✅ | ✅ | — |
| `public` | ✅ | ✅ | ✅ | ✅ |

### 使用建议

| 场景 | 推荐修饰符 |
|------|------------|
| 成员变量 | `private`（配合 getter/setter） |
| 对外提供的方法 | `public` |
| 仅供子类使用的方法 | `protected` |
| 工具类内部方法 | `private` |

## 七、Java 继承特点与 Object 类

### 7.1 Java 的继承特点

| 特点 | 说明 |
|------|------|
| **单继承** | 一个子类**只能有一个**直接父类 |
| **不支持多继承** | 不能同时 `extends` 多个类 |
| **支持多层继承** | A → B → C（C 间接继承 A 的成员） |

```java
// ✅ 单继承（合法）
class B extends A {}

// ❌ 多继承（非法，Java 不支持）
class C extends A, B {}

// ✅ 多层继承（合法）
class A {}
class B extends A {}
class C extends B {}   // C 间接继承了 A
```

---

### 7.2 Object 类

> **任意一个 Java 类都直接或间接继承 `Object` 类。**

| 特点 | 说明 |
|------|------|
| 所有类的根父类 | 未写 `extends` 的类，默认继承 `Object` |
| 通用方法 | `Object` 中所有**非私有成员**，任意 Java 类都可以使用 |

**Object 类常用方法（后续学习）：**

```java
toString()     // 返回对象的字符串表示
equals()       // 比较两个对象是否相等
hashCode()     // 返回对象的哈希码
getClass()     // 返回对象运行时的类
```
