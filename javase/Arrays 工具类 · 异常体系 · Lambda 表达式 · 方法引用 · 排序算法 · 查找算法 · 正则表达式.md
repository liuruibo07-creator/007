## 一、Arrays 工具类

### `sort()` 排序

- `Arrays.sort()` 底层**并非**使用冒泡或选择排序，而是综合采用 **快速排序、归并排序、插入排序**。
- ⚠️ **优先级规则**：当同时设置了自然排序和比较器排序（`Comparator`）时，**比较器排序优先级高**。

### `binarySearch()` 二分查找

- 要求数组必须**升序排列**才能使用。

## 二、异常（Exception）

### 2.1 异常体系结构

```
Throwable
├── Error（错误）
│     └── 严重问题，程序无法处理
│           示例：StackOverflowError（方法无限递归调用）
└── Exception（异常）
      ├── RuntimeException（运行时异常）
      │     └── 发生在运行阶段，编译不报错
      │           示例：ArrayIndexOutOfBoundsException
      └── 编译时异常（除 RuntimeException 及其子类外）
            └── 发生在编译阶段，编译报错，不处理无法运行
                  示例：ParseException
```

### 2.2 异常的处理方式

#### 方式一：JVM 默认处理

- 将异常的**名称、信息、报错位置**打印到控制台，并**终止程序**。

#### 方式二：`throws` 声明抛出

```java
// 语法
返回值类型 方法名(参数列表) throws 异常类型1, 异常类型2 { ... }
```

| 注意事项        | 说明                      |
| ----------- | ----------------------- |
| 运行异常可省略     | `throws` 声明的是运行时异常时可以不写 |
| 编译异常不能省略    | 编译时异常必须显式声明             |
| 子类异常 ≤ 父类异常 | 子类抛出的异常范围不能大于父类（编译时异常）  |
| 父子关系可简化     | 有继承关系时只写父类型即可           |

#### 方式三：`try-catch` 捕获处理

```java
try {
    // 可能出现异常的代码
} catch (异常类型1 e) {
    // 处理异常1
} catch (异常类型2 e) {
    // 处理异常2（父类异常要写在下面）
} finally {
    // 无论是否发生异常，都会执行（常用于释放资源）
}
```

**注意事项：**

1. `try` 中出现异常后，其后的代码**不再执行**。
2. 多个异常对应多个 `catch`，**父类异常必须写在后面**。
3. `catch` 从上到下依次匹配，类型匹配成功后**只执行一个**。
4. 只有进入 `catch` 才算真正处理了异常，之后才会执行后续代码。
5. `finally` 无论是否发生异常**必然执行**，通常用于**释放资源**。

### 2.3 手动抛出异常 `throw`

```java
throw new 异常类型("异常信息");
```

#### `throw` vs `throws` 区别

| 关键字      | 位置    | 作用             |
| -------- | ----- | -------------- |
| `throw`  | 方法体内  | 手动创建并抛出一个异常对象  |
| `throws` | 方法声明上 | 声明该方法可能抛出的异常类型 |

### 2.5 自定义异常类

**作用：** 让报错信息"见名知意"，通常结合 `throw` 使用。

**定义步骤：**

```java
// 1. 继承 RuntimeException
public class MyException extends RuntimeException {

    // 2. 生成空参构造（快捷键）
    public MyException() {}

    // 3. 生成带 message 参数的构造（快捷键）
    public MyException(String message) {
        super(message);
    }
}
```

## 三、Lambda 表达式

### 3.1 作用

JDK 8 新特性，用于**简化匿名内部类**的书写。

### 3.2 格式

```java
(被重写方法的形参列表) -> {
    被重写方法的方法体
}


//1.调用通用方法,通过匿名内部类实现  
    useInterA(new InterA() {  
        @Override  
        public void method1() {  
            System.out.println("匿名内部类实现");  
        }  
    });  
    //2.调用通用方法,通过lambda表达式实现  
    useInterA(()->{  
        System.out.println("lambda表达式实现");  
    });  
    
    public static void useInterA(InterA interA) {  
    interA.method1();  
  
  
}

```

### 3.3 使用前提：函数式接口

> **函数式接口** = 有且仅有**一个抽象方法**的接口

- `Object` 类中 `public` 的非 `final` 抽象方法（如 `toString`、`equals(boolean)`、`hashCode`(int)）**不算在内**。
- 可通过 `@FunctionalInterface` 注解校验。

### 3.4 书写技巧

**对着唯一的抽象方法来书写。**

### 3.5 与匿名内部类的区别

| 特性 | 匿名内部类 | Lambda 表达式 |
|---|---|---|
| 支持接口 | ✅ | ✅ |
| 支持抽象类/普通类 | ✅ | ❌ |
| 接口限制 | 无限制 | 只支持**函数式接口** |

### 3.6 省略模式

> 口诀：**左1右1，要么都省，要么都不省**

| 省略规则 | 说明 |
|---|---|
| 左边只有一个参数 | 可省略小括号 `()` |
| 右边只有一行代码 | 可省略大括号 `{}`、分号 `;`、`return` |
| 参数类型 | 要么全省略，要么全不省 |
| 右边的 `{}`、`;`、`return` | 要么全省略，要么全不省 |

## 四、方法引用

### 4.1 作用

JDK 8 新特性，用于**进一步简化 Lambda 表达式**的书写。

> Lambda 是自己定义方法；方法引用是**找别人已写好的方法**直接拿来用（功能需一致）。

---

### 4.2 四种分类

#### ① 静态方法引用

```java
// 格式
类名::静态方法名

// 前提
// - 静态方法的形参类型 与 抽象方法形参类型 一致
// - 静态方法的返回值类型 与 抽象方法返回值类型 一致


```

#### ② 实例方法引用

```java
// 格式
对象名::实例方法名

// 前提
// - 实例方法的形参类型 与 抽象方法形参类型 一致
// - 实例方法的返回值类型 与 抽象方法返回值类型 一致
```

#### ③ 特殊方法引用（类的实例方法引用）

```java
// 格式
类名::实例方法名

// 前提
// - 被引用的实例方法定义在抽象方法第一个形参的数据类型中
// - 抽象方法的第一个形参作为实例方法的调用者
// - 抽象方法的其余形参作为实例方法的入参
```

#### ④ 构造方法引用

```java
// 格式
类名::new

// 前提
// - 构造方法的形参类型 与 抽象方法形参类型 一致
// - 抽象方法的返回值类型 与 构造方法所属类名 一致
```

## 五、排序算法

### 5.1 冒泡排序（Bubble Sort）

**核心思想：**

1. 相邻元素两两比较，小的放左边，大的放右边。
2. 第一轮结束后，**最大值**确定在最右边；第二轮可少比较一次，依此类推。
3. `n` 个数据只需比较 **`n-1` 轮**（最后剩一个无需比较）。

```
[5, 3, 8, 1]  → 轮次1: 相邻比较，最大值8归位
               → 轮次2: 次大值归位
               → 轮次3: 排序完成
```

---

### 5.2 选择排序（Selection Sort）

**核心思想：**

1. 从索引 `0` 开始，与后续所有元素比较，**最小值放到左边**。
2. 第一轮结束后，最小值确定在索引 `0`；第二轮从索引 `1` 开始，依此类推。
3. `n` 个数据只需比较 **`n-1` 轮**。

---

## 六、查找算法

### 6.1 顺序查找（Sequential Search）

- **适用场景：** 元素**无序**时，只能使用顺序查找。
- **核心思想：** 从前向后依次遍历查找。

### 6.2 二分查找（Binary Search）

- **适用场景：** 元素**有序**时才能使用。
- **核心思想：** 每次查找缩小一半范围，大幅提升查找效率。

| 查找算法 | 前提 | 效率 |
|---|---|---|
| 顺序查找 | 无序或有序均可 | O(n) |
| 二分查找 | 必须有序（升序） | O(log n) |

## 七、正则表达式（Regular Expression）

### 7.1 概念与作用

- **定义：** 制定了一个匹配规则的式子（pattern）。
- **作用：**
  - ✅ 校验字符串格式是否合法（如手机号、邮箱验证）
  - ✅ 爬取/提取满足条件的内容

---

### 7.2 书写规则速查表

#### 字符类（匹配单个字符）

| 表达式 | 说明 |
|---|---|
| `[abc]` | 只能是 a、b 或 c |
| `[^abc]` | 除 a、b、c 之外的任何字符 |
| `[a-zA-Z]` | a 到 z 或 A 到 Z（范围） |
| `[a-z&&[def]]` | d、e 或 f（交集） |
| `[a-z&&[^bc]]` | a 到 z，除了 b 和 c |
| `[a-z&&[^m-p]]` | a 到 z，除了 m 到 p |

#### 预定义字符类（匹配单个字符）

| 表达式 | 说明 |
|---|---|
| `.` | 任意字符 |
| `\d` | 数字：`[0-9]` |
| `\D` | 非数字：`[^0-9]` |
| `\s` | 空白字符 |
| `\S` | 非空白字符 |
| `\w` | 单词字符：`[a-zA-Z_0-9]` |
| `\W` | 非单词字符 |

#### 数量词

| 表达式 | 说明 |
|---|---|
| `X?` | X，出现 0 次或 1 次 |
| `X*` | X，出现 0 次或多次 |
| `X+` | X，出现 1 次或多次 |
| `X{n}` | X，恰好 n 次 |
| `X{n,}` | X，至少 n 次 |
| `X{n,m}` | X，至少 n 次但不超过 m 次 |

#### 其他语法

| 语法 | 说明 |
|---|---|
| `()` | 分组 |
| `(?i)` | 忽略大小写 |
| `\|` | 或者关系（如 `cat\|dog`） |
