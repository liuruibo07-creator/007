# Tlias 智能学习辅助系统 —— 代码业务逻辑分析

> 涉及模块：登录功能 / 员工管理（增删改查）

---

## 一、项目整体路由结构（`router/index.js`）

系统采用 Vue Router 4 的 **History 模式**，路由分两层：

```
/              → LayoutView（主布局，重定向至 /Index）
├── /Index     → 首页
├── /Emp       → 员工管理
├── /Dept      → 部门管理
├── /Clazz     → 班级管理
├── /Stu       → 学生管理
├── /Log       → 日志管理
└── /Report    → 员工报表

/login         → 登录页（独立页面，不在主布局内）
```

**关键设计**：登录页 `/login` 与主布局是平级路由，不共享侧边栏/顶栏等布局组件，保证未登录时访问路由跳转至干净的登录界面。

## 二、登录功能（`views/login/index.vue` + `api/user.js`）

### 2.1 API 层

```js
// api/user.js
import request from "@/utils/request";

export function loginApi(data) {
    return request.post('/login', data);
}
```

- 封装 `POST /login` 请求，`data` 为包含 `username` 和 `password` 的对象。
- `request` 是基于 Axios 封装的实例，统一处理 baseURL、超时、拦截器等。

---

### 2.2 业务逻辑分析

| 步骤 | 说明 |
|------|------|
| ① 数据绑定 | 用 `ref` 定义响应式对象 `loginForm`，双向绑定用户名和密码输入框 |
| ② 调用接口 | 点击"登录"按钮触发 `login()`，`async/await` 等待接口响应 |
| ③ 成功处理 | `result.code` 为真值时：弹出成功提示、将用户信息存入 `localStorage`、跳转至首页 `/Index` |
| ④ 失败处理 | `result.code` 为假值时：弹出 `result.msg` 错误提示（兜底文案"登录失败"） |
| ⑤ 重置功能 | 点击"重置"按钮调用 `clear()`，将 `loginForm` 还原为空字符串 |

**数据持久化**：登录成功后执行：
```js
localStorage.setItem('loginUser', JSON.stringify(result.data))
```
将后端返回的用户信息（通常包含 token、用户名、头像等）序列化存储，后续请求拦截器从此处读取 token 添加到请求头。

---

### 2.3 登录模板代码

```vue
<script setup>
import { loginApi } from '@/api/user';
import { ElMessage } from 'element-plus';
import { ref } from 'vue';
import { useRouter } from 'vue-router';

// 表单响应式数据
let loginForm = ref({ username: '', password: '' });
const router = useRouter();

// 登录逻辑
async function login() {
    const result = await loginApi(loginForm.value);
    if (result.code) {
        ElMessage.success('登录成功');
        // 用户信息持久化
        localStorage.setItem('loginUser', JSON.stringify(result.data));
        // 跳转首页
        router.push('/Index');
    } else {
        ElMessage.error(result.msg || '登录失败');
    }
}

// 重置表单
function clear() {
    loginForm.value = { username: '', password: '' };
}
</script>

<template>
  <div id="container">
    <div class="login-form">
      <el-form label-width="80px">
        <p class="title">Tlias智能学习辅助系统</p>

        <el-form-item label="用户名" prop="username">
          <el-input v-model="loginForm.username" placeholder="请输入用户名" />
        </el-form-item>

        <el-form-item label="密码" prop="password">
          <el-input type="password" v-model="loginForm.password" placeholder="请输入密码" />
        </el-form-item>

        <el-form-item>
          <el-button class="button" type="primary" @click="login">登 录</el-button>
          <el-button class="button" type="info"    @click="clear">重 置</el-button>
        </el-form-item>
      </el-form>
    </div>
  </div>
</template>
```

## 三、员工管理增删改查（`api/emp.js` + `views/emp/index.vue`）

### 3.1 API 层

```js
// api/emp.js
import request from "@/utils/request";

// 分页查询
export function selectEmpByPageApi(params) {
    return request.get('/emps', { params });
}

// 新增员工
export const addEmpApi = (data) => request.post('/emps', data);

// 批量删除（ids 以逗号拼接）
export const deleteEmpApi = (ids) => request.delete(`/emps?ids=${ids}`);

// 根据 id 查询单个员工（用于回显编辑表单）
export const queryByIdApi = (id) => request.get(`/emps/${id}`);

// 修改员工信息
export const updateEmpApi = (data) => request.put('/emps', data);
```

各接口与后端 RESTful 规范对应关系：

| 操作 | HTTP 方法 | 接口路径 | 说明 |
|------|-----------|----------|------|
| 查询（分页） | GET | `/emps?page=1&pageSize=10&...` | params 作为 query string |
| 新增 | POST | `/emps` | data 为员工对象，JSON 请求体 |
| 删除（批量） | DELETE | `/emps?ids=1,2,3` | ids 数组拼接为字符串传参 |
| 查询单条 | GET | `/emps/{id}` | 路径参数 |
| 修改 | PUT | `/emps` | data 包含 id，JSON 请求体 |

---

### 3.2 查询（分页 + 条件搜索）业务逻辑

**核心流程：**

```
组件挂载(onMounted) / 点击搜索
    ↓
调用 selectEmpByPageApi(searchParams)
    ↓
后端返回 { total, rows }
    ↓
更新 empList（渲染表格）+ total（渲染分页器）
```

**参数设计：**

```js
// 搜索条件 + 分页参数合并为一个对象
const searchParams = ref({
    name: '',        // 姓名模糊搜索
    gender: '',      // 性别筛选
    begin: '',       // 入职开始时间
    end: '',         // 入职结束时间
    page: 1,         // 当前页码
    pageSize: 10,    // 每页条数
});
```

分页器 `current-change` 和 `size-change` 事件直接修改 `searchParams.page` 和 `searchParams.pageSize`，再重新调用查询方法，实现**无状态分页**。

### 3.3 新增员工业务逻辑

```
点击"新增"按钮
    ↓
重置 addForm 数据，dialogVisible = true（打开 Dialog）
    ↓
用户填写表单 → 点击"确认"
    ↓
表单校验（el-form ref.validate）
    ↓ 通过
调用 addEmpApi(addForm.value)
    ↓ 成功
ElMessage.success / 关闭 Dialog / 重新调用查询方法刷新列表
```

---

### 3.4 修改员工业务逻辑

```
点击行内"编辑"按钮，传入当前行 id
    ↓
调用 queryByIdApi(id) 获取完整员工数据（回显所有字段）
    ↓
将返回数据赋值给 editForm，editDialogVisible = true
    ↓
用户修改表单 → 点击"确认"
    ↓
表单校验通过
    ↓
调用 updateEmpApi(editForm.value)
    ↓ 成功
ElMessage.success / 关闭 Dialog / 重新查询刷新列表
```

> ⚠️ **为什么要先 `queryByIdApi` 而不是直接用表格行数据？**
> 表格列表数据往往是精简字段（用于展示），编辑时需要完整字段（如部门 id、职位、证件号等），必须单独查询以保证回显完整。

---

### 3.5 删除员工业务逻辑

**单个删除：**

```
点击行内"删除"按钮，传入 id
    ↓
ElMessageBox.confirm（二次确认弹框）
    ↓ 用户点击"确定"
调用 deleteEmpApi([id])   // 将单个 id 放入数组
    ↓ 成功
ElMessage.success / 重新查询刷新列表
```

**批量删除：**

```
用户勾选表格多行（el-table @selection-change 收集 ids）
    ↓
点击"批量删除"按钮
    ↓
判断 ids 数组是否为空，为空则提示"请先勾选数据"
    ↓
ElMessageBox.confirm 二次确认
    ↓ 用户点击"确定"
ids 数组 join(',') 拼接为字符串
    ↓
调用 deleteEmpApi(ids.join(','))
    ↓ 成功
ElMessage.success / 重新查询刷新列表
```

### 3.6 员工管理完整模板代码

```vue
<script setup>
import { ref, onMounted } from 'vue';
import { ElMessage, ElMessageBox } from 'element-plus';
import {
    selectEmpByPageApi,
    addEmpApi,
    deleteEmpApi,
    queryByIdApi,
    updateEmpApi,
} from '@/api/emp';

// ==================== 查询 ====================
const empList = ref([]);
const total = ref(0);
const searchParams = ref({
    name: '', gender: '', begin: '', end: '',
    page: 1, pageSize: 10,
});

async function loadEmpList() {
    const result = await selectEmpByPageApi(searchParams.value);
    if (result.code) {
        empList.value = result.data.rows;
        total.value = result.data.total;
    }
}

onMounted(() => loadEmpList());

function handleSearch() {
    searchParams.value.page = 1; // 搜索时重置到第一页
    loadEmpList();
}

function handlePageChange(page) {
    searchParams.value.page = page;
    loadEmpList();
}

function handleSizeChange(size) {
    searchParams.value.pageSize = size;
    searchParams.value.page = 1;
    loadEmpList();
}

// ==================== 新增 ====================
const addDialogVisible = ref(false);
const addFormRef = ref(null);
const addForm = ref({ name: '', gender: '', entryDate: '', deptId: '', job: '', image: '' });

function openAddDialog() {
    addForm.value = { name: '', gender: '', entryDate: '', deptId: '', job: '', image: '' };
    addDialogVisible.value = true;
}

async function confirmAdd() {
    await addFormRef.value.validate();
    const result = await addEmpApi(addForm.value);
    if (result.code) {
        ElMessage.success('新增成功');
        addDialogVisible.value = false;
        loadEmpList();
    }
}

// ==================== 编辑（修改）====================
const editDialogVisible = ref(false);
const editFormRef = ref(null);
const editForm = ref({});

async function openEditDialog(id) {
    const result = await queryByIdApi(id);
    if (result.code) {
        editForm.value = result.data;
        editDialogVisible.value = true;
    }
}

async function confirmEdit() {
    await editFormRef.value.validate();
    const result = await updateEmpApi(editForm.value);
    if (result.code) {
        ElMessage.success('修改成功');
        editDialogVisible.value = false;
        loadEmpList();
    }
}

// ==================== 删除 ====================
const selectedIds = ref([]);

function handleSelectionChange(selection) {
    selectedIds.value = selection.map(item => item.id);
}

async function deleteEmp(id) {
    await ElMessageBox.confirm('确认删除该员工？', '提示', { type: 'warning' });
    const result = await deleteEmpApi(String(id));
    if (result.code) {
        ElMessage.success('删除成功');
        loadEmpList();
    }
}

async function batchDelete() {
    if (selectedIds.value.length === 0) {
        ElMessage.warning('请先勾选要删除的员工');
        return;
    }
    await ElMessageBox.confirm(`确认删除选中的 ${selectedIds.value.length} 条数据？`, '提示', { type: 'warning' });
    const result = await deleteEmpApi(selectedIds.value.join(','));
    if (result.code) {
        ElMessage.success('批量删除成功');
        loadEmpList();
    }
}
</script>

<template>
  <div>
    <!-- 搜索栏 -->
    <el-form inline>
      <el-form-item label="姓名">
        <el-input v-model="searchParams.name" placeholder="请输入姓名" clearable />
      </el-form-item>
      <el-form-item label="性别">
        <el-select v-model="searchParams.gender" placeholder="请选择" clearable>
          <el-option label="男" value="1" />
          <el-option label="女" value="2" />
        </el-select>
      </el-form-item>
      <el-form-item label="入职时间">
        <el-date-picker v-model="searchParams.begin" type="date" placeholder="开始日期" value-format="YYYY-MM-DD" />
        <span style="margin: 0 6px">—</span>
        <el-date-picker v-model="searchParams.end" type="date" placeholder="结束日期" value-format="YYYY-MM-DD" />
      </el-form-item>
      <el-form-item>
        <el-button type="primary" @click="handleSearch">查询</el-button>
        <el-button @click="() => { Object.assign(searchParams, { name:'', gender:'', begin:'', end:'', page:1 }); loadEmpList(); }">重置</el-button>
      </el-form-item>
    </el-form>

    <!-- 操作按钮 -->
    <div style="margin-bottom: 12px">
      <el-button type="primary" @click="openAddDialog">+ 新增员工</el-button>
      <el-button type="danger"  @click="batchDelete">批量删除</el-button>
    </div>

    <!-- 员工表格 -->
    <el-table :data="empList" border @selection-change="handleSelectionChange">
      <el-table-column type="selection" width="50" />
      <el-table-column prop="name"      label="姓名"     />
      <el-table-column prop="image"     label="头像"     >
        <template #default="{ row }">
          <img :src="row.image" style="width: 40px; height: 40px; border-radius: 50%" />
        </template>
      </el-table-column>
      <el-table-column prop="gender"    label="性别"     :formatter="(row) => row.gender === 1 ? '男' : '女'" />
      <el-table-column prop="job"       label="职位"     />
      <el-table-column prop="entryDate" label="入职日期"  />
      <el-table-column prop="updateTime" label="最后操作时间" />
      <el-table-column label="操作" width="180">
        <template #default="{ row }">
          <el-button type="primary" size="small" @click="openEditDialog(row.id)">编辑</el-button>
          <el-button type="danger"  size="small" @click="deleteEmp(row.id)">删除</el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- 分页器 -->
    <el-pagination
      v-model:current-page="searchParams.page"
      v-model:page-size="searchParams.pageSize"
      :page-sizes="[10, 20, 50]"
      :total="total"
      layout="total, sizes, prev, pager, next"
      @current-change="handlePageChange"
      @size-change="handleSizeChange"
      style="margin-top: 16px"
    />

    <!-- 新增 Dialog -->
    <el-dialog v-model="addDialogVisible" title="新增员工" width="500px">
      <el-form ref="addFormRef" :model="addForm" label-width="80px">
        <el-form-item label="姓名"  prop="name"      :rules="[{ required: true, message: '请输入姓名' }]">
          <el-input v-model="addForm.name" />
        </el-form-item>
        <el-form-item label="性别"  prop="gender">
          <el-radio-group v-model="addForm.gender">
            <el-radio :label="1">男</el-radio>
            <el-radio :label="2">女</el-radio>
          </el-radio-group>
        </el-form-item>
        <el-form-item label="入职日期" prop="entryDate">
          <el-date-picker v-model="addForm.entryDate" type="date" value-format="YYYY-MM-DD" />
        </el-form-item>
        <el-form-item label="部门"  prop="deptId">
          <el-select v-model="addForm.deptId" placeholder="请选择部门" />
        </el-form-item>
        <el-form-item label="职位"  prop="job">
          <el-select v-model="addForm.job" placeholder="请选择职位" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="addDialogVisible = false">取消</el-button>
        <el-button type="primary" @click="confirmAdd">确认</el-button>
      </template>
    </el-dialog>

    <!-- 编辑 Dialog -->
    <el-dialog v-model="editDialogVisible" title="编辑员工" width="500px">
      <el-form ref="editFormRef" :model="editForm" label-width="80px">
        <el-form-item label="姓名"  prop="name"      :rules="[{ required: true, message: '请输入姓名' }]">
          <el-input v-model="editForm.name" />
        </el-form-item>
        <el-form-item label="性别"  prop="gender">
          <el-radio-group v-model="editForm.gender">
            <el-radio :label="1">男</el-radio>
            <el-radio :label="2">女</el-radio>
          </el-radio-group>
        </el-form-item>
        <el-form-item label="入职日期" prop="entryDate">
          <el-date-picker v-model="editForm.entryDate" type="date" value-format="YYYY-MM-DD" />
        </el-form-item>
        <el-form-item label="部门"  prop="deptId">
          <el-select v-model="editForm.deptId" placeholder="请选择部门" />
        </el-form-item>
        <el-form-item label="职位"  prop="job">
          <el-select v-model="editForm.job" placeholder="请选择职位" />
        </el-form-item>
      </el-form>
      <template #footer>
        <el-button @click="editDialogVisible = false">取消</el-button>
        <el-button type="primary" @click="confirmEdit">确认</el-button>
      </template>
    </el-dialog>
  </div>
</template>
```

## 四、关键设计模式总结

| 模式 | 体现位置 | 说明 |
|------|----------|------|
| **组合式 API（Composition API）** | 所有 `.vue` 文件 | 使用 `<script setup>` + `ref`，逻辑聚合度高 |
| **接口层分离** | `api/emp.js` / `api/user.js` | 所有 HTTP 请求封装在 api 目录，视图层只调用函数 |
| **响应式表单绑定** | `v-model` 绑定 `ref` 对象 | 输入框与数据实时同步，无需手动 DOM 操作 |
| **操作后刷新列表** | 增/删/改成功回调 | 统一调用 `loadEmpList()` 保证数据与后端一致 |
| **二次确认防误操作** | 删除操作 | `ElMessageBox.confirm` 拦截误点 |
| **搜索重置页码** | `handleSearch` | 避免搜索后停留在末页导致数据为空 |
