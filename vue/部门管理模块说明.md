# 部门管理模块实现说明

> 本文档说明 `dept.js`（API 封装层）与 `index.vue`（页面组件层）如何协作，完成部门的**增删改查**四项操作。

---

## 一、文件概览

| 文件 | 职责 |
|------|------|
| `dept.js` | 封装所有与后端交互的异步请求函数，统一管理接口路径 |
| `index.vue` | 页面逻辑与模板，调用 `dept.js` 中的函数，操控响应式数据，驱动 Element Plus 组件展示 |

---

## 二、dept.js — API 封装层

```js
import request from '@/utils/request'

export const queryAllDeptApi  = ()      => request.get('/depts')
export const addDeptApi        = (data) => request.post('/depts', data)
export const queryDeptByIdApi  = (id)   => request.get(`/depts/${id}`)
export const updateDeptApi     = (data) => request.put('/depts', data)
export const deleteDeptApi     = (id)   => request.delete(`/depts?id=${id}`)
```

`request` 是经过封装的 Axios 实例（`@/utils/request`），所有函数返回的都是 **Promise**，`await` 后得到的即为后端响应对象（以下统称 `result`）。

### 各函数的 result 内容

| 函数 | 请求方式 & 路径 | result 结构说明 |
|------|----------------|----------------|
| `queryAllDeptApi()` | `GET /depts` | `{ code: 1, data: [ { id, name, updateTime, ... }, ... ] }` — `data` 为部门列表数组 |
| `addDeptApi(data)` | `POST /depts` | `{ code: 1, data: null }` — 新增成功时 `code` 为 `1`，无返回业务数据 |
| `queryDeptByIdApi(id)` | `GET /depts/:id` | `{ code: 1, data: { id, name, updateTime, ... } }` — `data` 为单条部门对象 |
| `updateDeptApi(data)` | `PUT /depts` | `{ code: 1, data: null }` — 修改成功时 `code` 为 `1`，无返回业务数据 |
| `deleteDeptApi(id)` | `DELETE /depts?id=` | `{ code: 1, data: null }` — 删除成功时 `code` 为 `1`，无返回业务数据 |

> **约定**：`code: 1` 代表操作成功，`code: 0` 或其他值代表失败。`index.vue` 中所有的 `if(result.code)` 判断都基于这个约定。

## 三、index.vue — 页面逻辑层

### 3.1 响应式状态定义

```js
const deptList = ref([])              // 存放部门列表，绑定到表格
const dialogFormVisible = ref(false)  // 控制新增/编辑弹窗的显隐
const deptformRef = ref()             // 表单实例引用，用于触发校验/重置
const deptform = ref({ name: '' })    // 表单数据，新增时只有 name；编辑时还包含 id
const formTitle = ref('')             // 弹窗标题（"新增部门" / "编辑部门"）
```

表单校验规则：

```js
const rules = {
  name: [
    { required: true, message: '请输入部门名称', trigger: 'blur' },
    { min: 2, max: 10, message: '长度在 2 到 10 个字符', trigger: 'blur' }
  ]
}
```

### 3.2 查（Read）— `search()`

```js
async function search() {
  const result = await queryAllDeptApi()
  deptList.value = result.data
}

onMounted(() => {
  search()
})
```

**执行逻辑：**

1. 调用 `queryAllDeptApi()`，发送 `GET /depts`。
2. `result.data` 为部门数组，赋值给 `deptList`，Element Plus `<el-table>` 自动重新渲染。
3. 页面挂载时（`onMounted`）自动执行一次，保证初始数据加载。

**result 内容示例：**

```json
{
  "code": 1,
  "data": [
    { "id": 1, "name": "研发部", "updateTime": "2024-05-01T10:00:00" },
    { "id": 2, "name": "运营部", "updateTime": "2024-05-02T09:30:00" }
  ]
}
```

---

### 3.3 增（Create）— `showAddDialog()` + `saveOrUpdata()`

#### 打开新增弹窗

```js
const showAddDialog = () => {
  dialogFormVisible.value = true
  formTitle.value = '新增部门'
  deptformRef.value.resetFields()   // 重置表单，避免保留上次编辑的数据
}
```

#### 提交保存（新增分支）

```js
const saveOrUpdata = async () => {
  deptformRef.value.validate(async (valid) => {
    if (valid) {
      if (deptform.value.id) {
        // 有 id → 走修改逻辑（见 3.4）
      } else {
        // 无 id → 走新增逻辑
        const result = await addDeptApi(deptform.value)
        if (result.code) {
          ElMessage.success('增加成功')
          dialogFormVisible.value = false
          search()   // 刷新列表
        } else {
          ElMessage.error('添加错误')
        }
      }
    }
  })
}
```

**执行逻辑：**

1. 先通过 `validate` 校验表单（名称不能为空、2–10 个字符）。
2. `deptform.value` 中**无 `id` 字段**时，视为新增，调用 `addDeptApi({ name: '...' })`。
3. 根据 `result.code` 弹出成功/失败提示，成功后关闭弹窗并调用 `search()` 刷新表格。

**result 内容：**

```json
{ "code": 1, "data": null }
```

---

### 3.4 改（Update）— `showEditDialog(id)` + `saveOrUpdata()`

#### 打开编辑弹窗（数据回显）

```js
async function showEditDialog(id) {
  formTitle.value = '编辑部门'
  dialogFormVisible.value = true
  const result = await queryDeptByIdApi(id)
  if (result.code) {
    deptform.value = result.data   // 将后端数据填充到表单，包含 id
  }
}
```

**执行逻辑：**

1. 点击表格中的「编辑」按钮，传入当前行的 `id`。
2. 调用 `queryDeptByIdApi(id)`，发送 `GET /depts/:id`。
3. 将 `result.data`（含 `id`、`name` 等字段）赋值给 `deptform`，实现**数据回显**。

**result 内容：**

```json
{
  "code": 1,
  "data": { "id": 1, "name": "研发部", "updateTime": "2024-05-01T10:00:00" }
}
```

#### 提交保存（修改分支）

```js
// saveOrUpdata 内部，deptform.value.id 存在时走此分支
const result = await updateDeptApi(deptform.value)
if (result.code) {
  ElMessage.success('修改成功')
  dialogFormVisible.value = false
  search()
} else {
  ElMessage.error('添加错误')
}
```

**执行逻辑：**

1. 此时 `deptform.value` 包含 `id`（来自回显），调用 `updateDeptApi(deptform.value)`，发送 `PUT /depts`，请求体携带完整部门对象。
2. 根据 `result.code` 提示并刷新列表。

**result 内容：**

```json
{ "code": 1, "data": null }
```

---

### 3.5 删（Delete）— `showDeleteDialog(id)`

```js
function showDeleteDialog(id) {
  ElMessageBox.confirm('是否删除该部门', '提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning',
  })
  .then(async () => {
    // 用户点击「确定」
    const result = await deleteDeptApi(id)
    if (result.code) {
      ElMessage.success('删除成功')
      search()   // 刷新列表
    }
  })
  .catch((action) => {
    // 用户点击「取消」或关闭弹窗
    if (action === 'cancel' || action === 'close') {
      ElMessage.info('已取消删除')
    } else {
      ElMessage.error('删除失败')
    }
  })
}
```

**执行逻辑：**

1. 点击「删除」按钮，先用 `ElMessageBox.confirm` 弹出二次确认框，防止误操作。
2. 用户确认后，调用 `deleteDeptApi(id)`，发送 `DELETE /depts?id=xxx`。
3. 成功后刷新列表；取消则仅提示"已取消删除"。

**result 内容：**

```json
{ "code": 1, "data": null }
```

## 四、整体数据流图

```
用户操作（点击按钮）
       │
       ▼
  index.vue 函数（search / showAddDialog / showEditDialog / showDeleteDialog / saveOrUpdata）
       │
       ▼  调用
  dept.js API 函数（queryAllDeptApi / addDeptApi / queryDeptByIdApi / updateDeptApi / deleteDeptApi）
       │
       ▼  Axios 请求
  后端接口（/depts）
       │
       ▼  返回 { code, data }
  index.vue 根据 result.code 更新响应式数据 / 弹出提示 / 关闭弹窗 / 调用 search() 刷新
```

## 五、关键设计点总结

| 设计点 | 说明 |
|--------|------|
| 新增与修改共用 `saveOrUpdata` | 通过判断 `deptform.value.id` 是否存在来区分两种操作，减少重复代码 |
| 编辑前先调 `queryDeptByIdApi` | 保证表单数据与数据库最新数据一致，避免缓存脏数据 |
| 表单校验前置 | 只有 `validate` 通过后才发起网络请求，减少无效请求 |
| 删除二次确认 | `ElMessageBox.confirm` 防止误触，用户体验更安全 |
| 操作后统一调 `search()` | 增删改完成后立即刷新列表，保证页面数据与后端一致 |
