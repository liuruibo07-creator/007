## 一、Bean 作用域

Spring 通过 `@Scope` 设置 Bean 的作用域，最常用的是 `singleton` 和 `prototype`。

### 1. singleton：单例

```java
@Component
@Scope("singleton")
public class UserService {
}
```

特点：

- Spring IoC 容器中通常只有一个该 Bean 对象。
- 多次获取时得到同一个实例。
- Spring Bean 的默认作用域，不写 `@Scope` 即为单例。
- 容器负责其完整生命周期，包括创建、初始化和销毁。

```java
UserService bean1 = context.getBean(UserService.class);
UserService bean2 = context.getBean(UserService.class);

System.out.println(bean1 == bean2); // true
```

### 2. prototype：原型

```java
@Component
@Scope("prototype")
public class UserService {
}
```

特点：

- 每次向容器获取时都会创建一个新对象。
- 容器负责创建、依赖注入和初始化。
- Bean 交付给调用方后，Spring 通常不再管理其完整销毁过程。

```java
UserService bean1 = context.getBean(UserService.class);
UserService bean2 = context.getBean(UserService.class);

System.out.println(bean1 == bean2); // false
```

### 3. 作用域对比

| 对比项 | `singleton` | `prototype` |
|---|---|---|
| 实例数量 | 容器中通常一个 | 每次获取创建一个 |
| 是否默认 | 是 | 否 |
| 创建时机 | 通常随容器初始化 | 每次获取时 |
| 销毁管理 | 容器负责 | 通常由使用方负责 |
| 常见场景 | 无状态 Service、DAO | 需要独立状态的短期对象 |

> 单例 Bean 会被多个调用方共享，因此不应把某次请求的可变数据保存在普通实例字段中。

## 二、Bean 生命周期

Spring Bean 的简化生命周期：

```text
实例化
  ↓
依赖注入
  ↓
@PostConstruct 初始化方法
  ↓
Bean 对外提供服务
  ↓
@PreDestroy 销毁方法
```

### 1. `@PostConstruct`

添加在初始化方法上，在对象实例化和依赖注入完成后执行，通常只执行一次：

```java
@Component
public class DataService {

    @PostConstruct
    public void init() {
        System.out.println("初始化资源");
    }
}
```

常见用途：加载缓存、检查配置、初始化连接或其他资源。

### 2. `@PreDestroy`

添加在销毁方法上，在 Bean 被容器销毁前执行，通常只执行一次：

```java
@PreDestroy
public void destroy() {
    System.out.println("释放资源");
}
```

常见用途：关闭连接、停止线程、释放文件或网络资源。

> `@PreDestroy` 主要对容器完整管理的 Bean 生效；原型 Bean 通常不会由容器自动调用销毁回调。

## 三、第三方 Bean 注册与注入

第三方类不能直接修改源码添加 `@Component`，通常在配置类中通过 `@Bean` 注册。

### 1. 使用 `@Bean` 注册

```java
@Configuration
public class DataSourceConfig {

    @Bean
    public DataSource dataSource() {
        return new PooledDataSource();
    }
}
```

`@Bean` 的特点：

- 添加在配置方法上。
- 方法返回值注册到 IoC 容器。
- 默认 Bean 名称是方法名，即上例中的 `dataSource`。
- 可通过 `@Bean("名称")` 自定义名称。

### 2. 注入简单类型

先加载属性文件，再通过 `@Value` 注入配置值：

```java
@Configuration
@PropertySource("classpath:jdbc.properties")
public class DataSourceConfig {

    @Value("${jdbc.driver}")
    private String driver;

    @Value("${jdbc.url}")
    private String url;

    @Value("${jdbc.username}")
    private String username;

    @Value("${jdbc.password}")
    private String password;

    @Bean
    public DataSource dataSource() {
        PooledDataSource dataSource = new PooledDataSource();
        dataSource.setDriver(driver);
        dataSource.setUrl(url);
        dataSource.setUsername(username);
        dataSource.setPassword(password);
        return dataSource;
    }
}
```

### 3. 注入引用类型

在 `@Bean` 方法中直接声明形参，Spring 会从容器中查找并注入：

```java
@Bean
public SqlSessionFactoryBean sqlSessionFactory(
        DataSource dataSource
) {
    SqlSessionFactoryBean factory = new SqlSessionFactoryBean();
    factory.setDataSource(dataSource);
    return factory;
}
```

```text
简单值 → @Value 注入
引用 Bean → @Bean 方法形参注入
```

## 四、Spring 整合 MyBatis

### 1. 整合目的

将 MyBatis 的 Mapper 代理对象注册到 Spring IoC 容器，之后可直接在 Service 中注入 Mapper，无需手动创建 `SqlSessionFactory`、打开 `SqlSession` 和调用 `getMapper()`。

### 2. 主要依赖

项目通常需要：

- Spring Context。
- Spring JDBC。
- MyBatis。
- MyBatis-Spring。
- 数据库驱动。
- 数据源组件。

版本应根据项目约束统一选择。

### 3. MyBatis 配置类

```java
@Configuration
public class MyBatisConfig {

    @Bean
    public SqlSessionFactoryBean sqlSessionFactory(
            DataSource dataSource
    ) {
        SqlSessionFactoryBean factory = new SqlSessionFactoryBean();
        factory.setDataSource(dataSource);
        factory.setTypeAliasesPackage("com.edu.entity");
        return factory;
    }

    @Bean
    public MapperScannerConfigurer mapperScannerConfigurer() {
        MapperScannerConfigurer scanner =
                new MapperScannerConfigurer();
        scanner.setBasePackage("com.edu.mapper");
        return scanner;
    }
}
```

### 4. 两个核心组件

| 组件 | 作用 |
|---|---|
| `SqlSessionFactoryBean` | 创建并向容器提供 `SqlSessionFactory` |
| `MapperScannerConfigurer` | 扫描 Mapper 接口并注册对应代理对象 |

`SqlSessionFactoryBean` 实现了 Spring 的 `FactoryBean`：容器中主要使用的是其 `getObject()` 创建的 `SqlSessionFactory`。

### 5. 导入配置

```java
@Configuration
@ComponentScan("com.edu")
@Import({DataSourceConfig.class, MyBatisConfig.class})
public class SpringConfig {
}
```

### 6. Service 中使用 Mapper

```java
@Service
public class UserServiceImpl implements UserService {

    private final UserMapper userMapper;

    public UserServiceImpl(UserMapper userMapper) {
        this.userMapper = userMapper;
    }

    @Override
    public List<User> selectAll() {
        return userMapper.selectAll();
    }
}
```

## 五、Spring 整合 JUnit 5

### 1. 整合目的

让测试类使用 Spring 测试上下文，直接注入容器中的 Bean 进行测试，不需要在每个测试方法中手动创建 IoC 容器。

### 2. 依赖组成

主要包括：

- Spring Context。
- Spring Test。
- JUnit Jupiter。

### 3. 测试类写法

```java
@SpringJUnitConfig(SpringConfig.class)
class UserServiceTest {

    @Autowired
    private UserService userService;

    @Test
    void selectAll() {
        List<User> users = userService.selectAll();
        assertNotNull(users);
    }
}
```

`@SpringJUnitConfig(SpringConfig.class)` 会：

1. 指定 Spring 配置类。
2. 为测试创建 Spring 测试上下文。
3. 支持在测试类中注入 Bean。

## 六、AOP 概述

AOP（Aspect-Oriented Programming，面向切面编程）是对面向对象编程的补充。

它可以在不直接修改目标方法源代码的情况下，对一批方法统一增强。Spring AOP 底层主要通过动态代理实现。

常见用途：

- 日志记录。
- 性能统计。
- 权限校验。
- 事务管理。
- 异常监控。

```text
目标方法原有逻辑
       +
日志、事务、权限等通用逻辑
       ↓ AOP 组合
代理对象中的增强方法
```

---

## 七、AOP 核心概念

| 概念 | 英文 | 含义 |
|---|---|---|
| 连接点 | Join Point | 程序执行过程中可以被增强的位置；Spring AOP 中主要指方法执行 |
| 切入点 | Pointcut | 实际被规则选中的连接点，即需要增强的方法 |
| 通知 | Advice | 在切入点执行的增强逻辑 |
| 切面 | Aspect | 切入点与通知的组合 |
| 目标对象 | Target | 原始业务对象 |
| 代理对象 | Proxy | Spring 创建的、包含增强逻辑的对象 |

核心关系：

```text
切面 = 切入点 + 通知
```

## 八、AOP 入门实现

### 1. 引入依赖

通常需要：

- `spring-context`：会传递引入 `spring-aop`。
- `aspectjweaver`：支持 AspectJ 切入点表达式和相关能力。

### 2. 开启 AOP

```java
@Configuration
@ComponentScan("com.edu")
@EnableAspectJAutoProxy
public class SpringConfig {
}
```

### 3. 定义切面类

```java
@Component
@Aspect
public class LogAspect {

    @Pointcut("execution(* com.edu.service.*.*(..))")
    public void servicePointcut() {
        // 仅用于承载切入点表达式
    }

    @Before("servicePointcut()")
    public void beforeAdvice() {
        System.out.println("方法执行前记录日志");
    }
}
```

关键注解：

| 注解 | 作用 |
|---|---|
| `@Component` | 将切面类注册为 Bean |
| `@Aspect` | 声明当前类是切面类 |
| `@Pointcut` | 定义需要增强的方法集合 |
| `@Before` | 定义前置通知 |
| `@EnableAspectJAutoProxy` | 开启基于注解的 AOP 代理 |

### 4. 执行过程

```text
调用方调用代理对象
       ↓
执行 @Before 通知
       ↓
执行目标方法
       ↓
返回结果
```

## 九、切入点表达式

### 1. execution 语法

```text
execution(
    访问修饰符 返回值类型
    包名.类名或接口名.方法名(参数类型)
    异常类型
)
```

访问修饰符和异常类型通常可以省略。

精确示例：

```java
@Pointcut("execution(void com.edu.service.UserService.save())")
```

常用示例：

```java
@Pointcut("execution(* com.edu.service.*.*(..))")
```

含义：匹配 `com.edu.service` 包下所有类或接口中的任意方法，返回值和参数均不限。

### 2. 通配符

| 通配符 | 含义 | 示例 |
|---|---|---|
| `*` | 单个任意内容 | 任意返回值、类名或方法名 |
| `..` | 多个连续任意内容 | 任意层级包、任意数量参数 |

示例：

```java
// service 包及其子包中的任意方法
execution(* com.edu.service..*.*(..))
```

### 3. 书写建议

- 尽量面向接口或稳定的业务包描述。
- 通常省略访问修饰符和异常声明。
- 表达式要尽量精确，避免错误增强无关方法。
- 可抽取公共 `@Pointcut`，由多个通知复用。

## 十、通知类型

Spring AOP 常用通知如下：

| 通知 | 注解 | 执行时机 |
|---|---|---|
| 前置通知 | `@Before` | 目标方法执行前 |
| 后置通知 | `@After` | 目标方法结束后，无论是否异常 |
| 返回通知 | `@AfterReturning` | 目标方法正常返回后 |
| 异常通知 | `@AfterThrowing` | 目标方法抛出异常后 |
| 环绕通知 | `@Around` | 包围目标方法，可决定是否执行目标方法 |

环绕通知示例：

```java
@Around("servicePointcut()")
public Object recordTime(ProceedingJoinPoint joinPoint)
        throws Throwable {
    long start = System.currentTimeMillis();

    try {
        return joinPoint.proceed();
    } finally {
        long elapsed = System.currentTimeMillis() - start;
        System.out.println("耗时：" + elapsed + " ms");
    }
}
```

`joinPoint.proceed()` 表示执行原始目标方法；遗漏它会导致目标方法不执行。

## 十一、重点速记

> [!TIP]
> **Bean 由 IoC 容器管理，MyBatis Mapper 可注册为 Bean，AOP 通过代理对象统一增强方法。**

- Bean 默认作用域是 `singleton`。
- `prototype` 每次获取都创建新对象，容器通常不负责销毁。
- `@PostConstruct` 在实例化、依赖注入后执行初始化。
- `@PreDestroy` 在容器销毁单例 Bean 前执行。
- `@Bean` 将配置方法的返回值注册到容器，默认名称为方法名。
- 简单配置值可用 `@Value` 注入。
- `@Bean` 方法形参可自动注入其他 Bean。
- `SqlSessionFactoryBean` 创建 `SqlSessionFactory`。
- `MapperScannerConfigurer` 扫描 Mapper 接口并注册代理对象。
- `@SpringJUnitConfig` 让 JUnit 5 测试使用 Spring 容器。
- AOP 是面向切面编程，Spring AOP 主要通过动态代理实现。
- 连接点是可增强的方法，切入点是实际被选中的方法。
- 通知是增强逻辑，切面等于切入点加通知。
- `@Aspect + @Component` 定义并注册切面类。
- `@EnableAspectJAutoProxy` 开启注解 AOP。
- `@Pointcut` 定义切入点，`@Before` 定义前置通知。
- `*` 表示单个任意内容，`..` 表示多个任意内容。
- `@Around` 中必须调用 `proceed()` 才会执行目标方法。
